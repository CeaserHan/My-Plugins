# 即梦 Seedance 2.0 中文提示词格式规范

## 标准结构（标签顺序固定）

```
【主体】...【动作】...【场景】...【光影】...【镜头】...【风格】...【画质】4K超高清，电影质感，画面稳定，细节丰富【约束】五官清晰，面部稳定不变形，人体结构正常，比例自然，动作流畅负向约束：无文字，无水印，无闪烁，无重影
```

---

## 各标签详解

### 【主体】
描述画面中的人/物，**不写外貌、服装、发型**（这些由角色参考图控制）。
- ✅ 好：`一个男人，背对镜头`、`两个人面对面坐着`
- ❌ 坏：`穿红色衬衫的男人`（服装不写）

### 【动作】
**节拍序列**，用"→"连接，而不是单一动词。

- ✅ 好：`缓缓转头 → 眼神落在桌上的信封上 → 停顿，没有拿起来`
- ❌ 坏：`看向桌子`（太简单，模型会生成静止姿态）

节拍数量建议与时长匹配：4秒镜头 2-3个节拍，8秒镜头 3-5个节拍。

### 【场景】
空间 + 时间 + 氛围三要素。
- 示例：`破旧公寓卧室，深夜，昏暗凌乱`
- 示例：`阳光明媚的街边咖啡馆，午后，暖意融融`

### 【光影】
光源 + 光质 + 方向 + 色温，**不要写"打光精美"这类无意义形容词**。
- ✅ `窗外冷白自然光从左侧斜入，室内暖黄台灯从右侧补光，冷暖对比明显`
- ✅ `正午强烈阳光从头顶直射，硬光，人物单侧阴影深浓`
- ❌ `光线很好`、`唯美打光`

### 【镜头】
景别 + 运动方式。

| 景别 | 用途 |
|------|------|
| 远景 | 建立空间，展示环境 |
| 全景 | 人物全身 + 场景关系 |
| 中景 | 叙事主力镜头，人物腰部以上 |
| 近景 | 情绪聚焦，人物胸部以上 |
| 特写 | 面部/道具细节，强调转折点 |
| 大特写 | 眼睛/手/关键细节 |

| 运动 | 用途 |
|------|------|
| 固定（无运动）| 稳定叙事，强调静止感 |
| 缓缓推近 | 建立情绪张力 |
| 缓缓拉远 | 角色与环境的疏离感 |
| 横移 | 跟随行走，或扫视空间 |
| 跟随 | 人物移动时同步跟随 |
| 手持微晃 | 纪录片质感，真实感 |
| 升镜头 | 揭示或告别感 |

### 【风格】
整体美学定调，这句话决定视频的"气质"。

| 常用风格 | 写法 |
|---------|------|
| 电影质感 | `电影质感，胶片色调，写实细腻` |
| 商业广告 | `商业广告风格，干净简洁，高饱和度` |
| 纪录片 | `纪录片风格，手持跟拍，真实感强` |
| 文艺片 | `文艺片质感，慢节奏，情绪留白` |
| 韩系氛围 | `韩系氛围感，柔和滤镜，画面细腻` |
| 王家卫风格 | `慢动作，暖色霓虹，时间感碎裂，情绪化构图` |

### 【画质】（固定写法，每次照抄）
```
4K超高清，电影质感，画面稳定，细节丰富
```

### 【约束】（固定写法，每次照抄）
```
五官清晰，面部稳定不变形，人体结构正常，比例自然，动作流畅
```

### 台词（如有）
写在约束后，格式：`人物说："台词原文。"`

### 负向约束（每次必须加，固定写法）
```
负向约束：无文字，无水印，无闪烁，无重影
```

## 完整示例

**剧本台词场景**：
```
【主体】一个中年男人，坐在餐桌边，面对一个空位【动作】缓缓放下筷子 → 看向对面空位 → 闭眼，深吸一口气【场景】普通家庭饭厅，傍晚，桌上摆着两副碗筷，只有他一人在吃【光影】暖黄吊灯从正上方照下，光线温暖但气氛孤寂【镜头】近景，固定机位【风格】写实家庭剧质感，情绪克制，细节真实【画质】4K超高清，电影质感，画面稳定，细节丰富【约束】五官清晰，面部稳定不变形，人体结构正常，比例自然，动作流畅负向约束：无文字，无水印，无闪烁，无重影
```

**小说情绪场景**：
```
【主体】一个女孩，站在大雨中的街边，没有打伞【动作】仰头看向天空 → 闭上眼睛 → 缓缓张开双臂【场景】城市街道，深夜暴雨，路灯昏黄，行人稀少【光影】路灯从侧上方打下暖黄光，雨水折射光斑，背景远处有车灯冷光【镜头】全景，镜头缓缓升起【风格】文艺片质感，情绪化构图，雨夜氛围浓郁【画质】4K超高清，电影质感，画面稳定，细节丰富【约束】五官清晰，面部稳定不变形，人体结构正常，比例自然，动作流畅负向约束：无文字，无水印，无闪烁，无重影
```

## 常见错误速查

| 错误写法 | 正确做法 |
|---------|---------|
| 写服装/发型：`穿红色大衣的女人` | 去掉服装：`一个女人，背对镜头` |
| 动作太简单：`她哭了` | 节拍化：`她低下头 → 肩膀微微颤抖 → 用手背擦了一下眼睛` |
| 光线描述模糊：`光线很美` | 具体化：`暖黄吊灯从右侧斜射，窗外冷白月光从左侧透入` |
| 忘记负向约束 | 每次必须加：`负向约束：无文字，无水印，无闪烁，无重影` |
| 忘记画质/约束标签 | 这两个标签固定照抄，不要省略 |
