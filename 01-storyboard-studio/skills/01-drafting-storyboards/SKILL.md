# 01-分镜草稿

把叙事文本转成由用户锁定的单行分镜草稿。完成草稿审核后必须停止，不得在同一回答继续长镜头或详细镜头设计。

## 先加载

1. 读取 [工作流契约](../../references/workflow-contract.md)、[分镜草稿作业手册](../../references/drafting-playbook.md)和[景别规则](../../references/visual-language/rules/1-shot-scale-rules.md)。需要例外或复核时读取对应[景别完整原文](../../references/visual-language/library/1.景别-shot-scale.md)。
2. 用户主动要求推荐创作者或明确指定创作者时，读取[创作者选择指南](../../references/directing/selection-guide.md)与[创作者索引](../../references/directing/creator-index.md)。
3. 用户选择库内创作者后，按索引读取该创作者在 `../../references/directing/library/` 的完整原文。索引不得代替原文。
4. 用户没有提出创作者需求时进入通用模式，不加载创作者索引或原文。

## 入口判断

- 缺少原始叙事文本：索取文本后停止。
- 用户未提创作者：进入通用模式，直接依据叙事、场面与视觉语言规则生成草稿；`本次对标` 写明“通用模式，无主参考创作者”。
- 用户主动要求推荐创作者：从索引推荐三位，分别说明适配原因、主要取舍和完整原文文件；停止等待选择，不得先出草稿。
- 用户指定库内创作者：读取其完整原文后继续。
- 用户指定库外创作者：说明本地没有完整资料，让用户选择使用通用知识或库内替代；决定前停止。
- 最多一个主参考和一个辅助参考。辅助参考只在用户明确指定的单一维度生效；否则只使用主参考。

## 执行

1. 在内部锁定人物关系、事件顺序、原有台词、关键道具、动机、动作结果、地点和时间变化。
2. 把心理和叙述转换为不改事实的可见动作；不能可靠外化的内容标为待确认。
3. 设计全场分镜节奏：确定信息揭示顺序、镜头密度变化、反应时机和场尾收束，再据此拆镜。
4. 依据事件、动作、台词、反应、道具状态和信息揭示拆镜。
5. 为每镜设计服务其主要信息的景别，并把相邻镜头放入完整景别曲线复核。不要写机位、纵轴向方位角、俯仰、运镜、焦段、音效或音乐。
6. 按以下固定顺序输出，不添加旧版附加审读环节：
   - 本次对标
   - 导演讲戏稿
   - 批注提示
   - 场景视觉基调
   - 单行分镜草稿
   - 草稿审核

导演讲戏稿必须明确分镜节奏和景别曲线：写清信息怎样分阶段揭示、镜头密度怎样变化、何时靠近或拉远、反应何时出现，以及场尾怎样收束。用户批准完整草稿后，这两项与镜头 ID、顺序和景别一起锁定。

## 单行草稿契约

每镜恰好一个物理行，只允许四种信息：镜头 ID、景别、可见动作、可选原有台词。

```text
S05｜中近景（林禾）｜林禾站在门口看向周芸。｜林禾：{“今天有我的信吗？”}
S06｜特写（周芸的手）｜削皮刀停在苹果表面。
```

- ID 从 `S01` 连续编号；不要用表格。
- 台词逐字保留并使用 `角色：{“台词”}`。
- 无台词时省略最后一段，不写“无台词”。
- 禁止出现机位、运镜、焦段、毫米数、音效、BGM或配乐。

## 审批门

草稿审核结尾必须明确要求用户回传修改后的完整草稿，或明确且无歧义地批准当前完整草稿。然后立即停止。

- `草稿不做修改`、“这版没问题，锁定吧”、`确认按当前完整草稿执行` 等明确指向当前完整草稿且表达无修改/锁定意图的回复：批准当前完整草稿。
- 用户回传格式有效的完整修改稿：以回传稿为新锁定版本。
- 孤立的 `继续`、`下一步`、`可以`、`往下`：不是批准，因为没有明确指向当前完整草稿；提醒用户补充锁定意图后继续等待。

不得替用户批准，不得把本轮草稿直接交给详细设计。批准后，分镜节奏和景别曲线均成为详细镜头设计不可修改的输入。
