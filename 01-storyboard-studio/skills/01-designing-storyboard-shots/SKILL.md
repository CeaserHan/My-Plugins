# 01-分镜镜头设计

把明确确认的最终草稿扩写成可执行的详细镜头。只做摄影、调度、构图、表演和声音设计；读取并保持草稿阶段已经锁定的分镜节奏和景别，不重新设计或改动。

## 分层加载

1. 始终读取[工作流契约](../../references/workflow-contract.md)、[连续性协议](../../references/continuity-protocol.md)、[本场视觉策略协议](../../references/visual-strategy-protocol.md)、[景别规则](../../references/visual-language/rules/1-shot-scale-rules.md)、[机位规则](../../references/visual-language/rules/2-camera-setup-rules.md)、[调度规则](../../references/visual-language/rules/6-blocking-rules.md)和[构图规则](../../references/visual-language/rules/7-composition-rules.md)。
2. 按场景条件加载其余规则：
   - 用户要求显示焦段，或场景涉及明显透视、空间压缩、畸变与镜间透视匹配时，读取[焦段规则](../../references/visual-language/rules/3-focal-length-rules.md)。
   - 用户要求运镜，或场景包含跟随、揭示、动作路径、失控与空间关系重构时，读取[运镜规则](../../references/visual-language/rules/4-camera-movement-rules.md)。
   - 场景包含两人以上关系、视线匹配、方向性运动或越轴风险时，读取[轴线规则](../../references/visual-language/rules/5-axis-line-rules.md)。
   - 用户指定光色，或场景存在多光源、走位受光变化、跨镜光线连续性时，读取[影调与色彩规则](../../references/visual-language/rules/8-light-and-color-rules.md)。
3. 规则冲突、例外或复核时，读取对应的 `../../references/visual-language/library/` 完整原文；没有触发条件时不要预加载全文。
4. 创作者模式读取[创作者选择指南](../../references/directing/selection-guide.md)、[创作者索引](../../references/directing/creator-index.md)和选中创作者完整原文。通用模式无需创作者资料，不以缺少创作者为由暂停。

## 硬入口

必须同时具备：

- 原始叙事文本；
- 用户最终确认的完整草稿；
- 明确的确认记录：回传完整修订稿，或明确且无歧义地批准当前完整草稿；
- 当前模式：通用模式，或已经选择并可读取资料的创作者模式。

任一缺失就停止并索取。孤立的 `继续`、`下一步`、`可以`、`往下` 不是确认记录。库外创作者按选择指南处理，用户决定前停止。

## 锁定审计

把最终草稿登记为不可变契约。不得改变镜头数量、编号、顺序、景别、台词、叙事事实和主要动作。若详细设计需求与草稿冲突，列出准确镜头 ID、锁定内容和冲突内容，然后停止；不要静默重拆、合并、增删或改写。

## 隐藏准备

### 连续性账本

按连续性协议记录人物外观与服装、站位、朝向、动作顺序、道具状态、场景空间、关系/视线/运动轴和光源方向。逐镜更新，默认不展示。

### 本场视觉策略

按视觉策略协议从最终草稿读取并冻结分镜节奏和景别曲线，再为每场建立：眼高、腰高、膝高、贴地、高位的机位高度逻辑；俯仰与纵轴向方位角变化路径；固定、摇移、推拉、跟拍、手持的运镜曲线；人物与场景调度、距离与权力变化；三类轴线；构图焦点、视线路径与留白；光源、影调与色彩连续性；内部焦段与透视匹配；创作者模式下选中创作者原文与场景节拍的对应方法。

创作者模式由主参考控制整场。最多一个辅助参考，且只作用于用户明确选定的单一维度；禁止风格拼盘。不得把创作者简化为色调、固定镜头、对称或少数标志性术语。通用模式直接依据锁定草稿和已触发的视觉规则建立策略。

## 输出模式

- 默认使用标准模式：在普通 Markdown 标题下只写三至六条本场执行原则；详细镜头保持完整；成品审查压缩为三项结论。用户复制到 Seedance 2.0 时只需复制 `text` 代码块。
- 用户明确要求 `制片审计模式`、完整导演形式分析、逐项证据或技术复盘时，使用制片审计模式：在同一导演形式分析区域内补全构图、运镜、机位角度、调度和执行原则，并在三项成品审查中给出逐镜证据。
- 两种模式使用相同的 Seedance 固定开场、每镜两行单行格式和锁定审计，不得为了缩短标准模式而删减镜头内容。

## 导演形式分析

完成锁定审计和隐藏准备后建立本场形式分析。标准模式只输出三至六条可核对的执行原则；制片审计模式增加以下内容：

- `### 构图美学`：视觉焦点顺序、人物与空间关系、遮挡、留白、框中框、前中后景或几何分区怎样服务当前叙事。
- `### 运镜策略`：固定、摇移、推拉、跟拍或手持怎样响应锁定动作和信息节点，不改变景别或重组分镜节奏。
- `### 摄像机机位角度策略`：机位高度、俯仰和纵轴向方位角怎样随信息、关系、表演和空间状态变化。
- `### 人物与场景调度`：人物站位、朝向、距离、遮挡、进入退出、道具互动和场景路径怎样形成可拍关系。
- `### 本场执行原则`：把结论压缩为三至六条原则；每条写清适用镜头范围。

创作者模式只使用已读取原文中与当前场景直接相关的方法；通用模式依据锁定草稿和视觉规则分析。不要写创作者生平、作品清单或泛化风格标签。不得重新分析、评价或修改已锁定的分镜节奏和景别；若认为二者有问题，报告受影响镜头 ID 并回到草稿阶段。

## 逐镜设计

1. 保留锁定 ID、顺序、分镜节奏与景别，先从连续性账本读取本镜开始状态。
2. 机位高度只从 `眼高、腰高、膝高、贴地、高位` 选择，再与平视、俯视或仰视组合；不写详细度数。
3. 写纵轴向方位角，例如 `纵轴向正视`、`纵轴向侧视`、`纵轴向左四分之三侧`、`纵轴向右四分之三侧`、`纵轴向背面`、`纵轴向左后四分之三侧`、`纵轴向右后四分之三侧`。完整写法示例：`眼高机位平视，纵轴向左四分之三侧，固定镜头`。
4. 无运动写 `固定镜头`。摄像机基本不移但有手持质感写 `手持观察`。随主体改变位置写 `前置跟拍`、`后置跟拍` 或 `侧向跟拍`，并注明轨道、稳定器或手持质感。推拉和跟拍只能在锁定景别允许的画面范围内执行，不得借运镜改变本镜景别。
5. 写最终可见的画面关系、必要构图、调度和人物表演。按镜头功能决定是否描述前景、中景、后景；特写、人物近景、俯视大全景和干净全景等不得机械补齐层次。
6. 焦段始终参与内部判断，但默认不输出焦段、毫米数、广角透视或长焦压缩。只有用户明确要求显示时才加入。
7. 第二行逐字保留原台词。只有原文明确存在声音，或本镜可见动作直接产生不可忽略的声音变化时，才写具体音效；禁止新增台词、人物含混说话、咳嗽、呼吸或其他未经原文支持的声音事件。没有新增声音事件时写 `音效：<无新增音效，延续场景环境声>。`
8. 更新本镜结束状态，再进入下一镜。

## 默认值审查

- 逐镜检查固定、摇移、推拉、跟拍、手持是否各有明确的信息、关系、路径或失控功能；没有功能就使用固定镜头。
- 重复使用同一机位高度、俯仰或纵轴向方位角不构成问题，只检查它是否让关键信息不可读或造成无意方向跳变。
- 克制对白、观察和等待允许连续使用固定和平视镜头；动作场面也允许固定镜头保持空间清晰。
- 不得把比例当作设计目标或通过增减运镜迎合指标。成品审查只报告有动机的变化路径，不计算固定镜头或机位组合的达标比例。

## 固定成品格式

成品严格按“导演形式分析—详细镜头设计—成品审查”的顺序输出。导演分析和成品审查使用普通 Markdown 直接显示；复制到 Seedance 2.0 时只复制中间的 `text` 代码块。

```markdown
## 导演形式分析

标准模式写三至六条本场执行原则；制片审计模式写完整形式分析。
```

随后输出 `## 详细镜头设计`，把固定开场和全部镜头放进同一个 `text` 代码块。

详细镜头设计代码块开头逐字输出以下两行，第二行必须另起一行：

````markdown
```text
参考<>中人物外观；参考<>场景氛围；参考<>道具。
禁止BGM，禁止配乐，禁止字幕，禁止logo，保持角色外观、服装、场景空间、光源方向和动作顺序一致；同一角色只生成一个对应主体，禁止分身、双胞胎或重复复制。
S05｜中近景（林禾），眼高机位平视，纵轴向左四分之三侧，固定镜头，前景门框压住画面左缘，中景的林禾停在门口右侧三分线上，面前留出朝向周芸的视线空间，后景保持简洁。她没有靠近，始终朝向周芸。
台词：林禾：{“今天有我的信吗？”}，音效：<无新增音效，延续场景环境声>。

S06｜特写（周芸的手），腰高机位平视，纵轴向侧视，固定镜头，周芸握刀的手停在苹果表面，刀锋与果皮保持清楚，动作停顿成为本镜唯一视觉重点。
音效：<无新增音效，延续场景环境声>。
```
````

- 每镜恰好两个物理行；第一行写镜头设计，第二行写原台词与音效，或只写音效。单行长描述是 Seedance 2.0 输入契约，不得拆成多行字段。
- 相邻镜头之间空一行；同一镜头的两行之间不得插入空行。
- 不用表格，不在镜内增加字段标题，不为单个镜头另开代码块。
- 无台词且没有新增声音事件时，第二行写 `音效：<无新增音效，延续场景环境声>。`；不要为了填充第二行发明具体声音。
- 不得输出 BGM、配乐、字幕或 logo 内容；固定开头中的禁止声明除外。

代码块之后输出普通 Markdown 标题：

```markdown
## 成品审查
```

标准模式每项给出简短结论；制片审计模式引用具体镜头 ID 和证据。固定为三项：

1. `### 形式与调度落实审查`：核对执行原则、构图焦点、遮挡、人物站位、进入退出和道具互动是否落实。
2. `### 运镜与机位角度变化审查`：核对每次运镜、机位高度、俯仰和纵轴向方位角变化是否有叙事动机；不计算达标比例。
3. `### 连续性与锁定指令审查`：核对原始文本、最终草稿、用户补充指令、镜头数、ID、顺序、景别、台词、主要动作、道具、光源和信息揭示顺序。

每项给出 `达标` 或 `需调整`。不得仅凭色调、题材或单个标志性构图宣称符合创作者方法。若修正会违反锁定草稿，保留锁定内容并报告准确镜头 ID，不得静默改稿或伪造达标结论。

## 最终核对

逐镜比较锁定草稿，确认镜头数、ID、顺序、分镜节奏、景别、台词、事实和主要动作完全不变；再核对连续性账本、已触发视觉规则、创作者模式下的原文映射、纵轴向方位角变化路径、单一 `text` 代码块、固定 Seedance 开场、镜间空行、每镜两行格式、台词花括号、音效尖括号和默认无焦段。发现冲突就报告并停止，不提交带静默改写的成品。
