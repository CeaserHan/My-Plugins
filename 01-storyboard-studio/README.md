# 01-分镜工作室

这是一个轻量 Codex 插件，以两个不可绕过的用户审查门把分镜工作拆成三个独立 Skill：

1. `01-drafting-storyboards`：把剧本、小说或场次文本拆成简洁单行草稿；未提创作者时使用通用模式，输出后停止。
2. `01-merging-long-takes`：可按请求推荐长镜头候选；只有用户明确指定镜头编号并要求合并时，才改写草稿并再次停止。
3. `01-designing-storyboard-shots`：只对明确确认的最终草稿进行机位、运镜、调度、构图、表演、按需声音与连续性设计，默认输出 Seedance 2.0 标准模式，也支持制片审计模式。

插件没有外部服务、数据库或运行时代理。`references/visual-language/library/` 与 `references/directing/library/` 保存完整原文；视觉语言的 `rules/` 是带来源映射的操作规则，创作者资料不建立方法卡。

## 审批语义

- 孤立的 `继续`、`下一步`、`可以`、`往下` 不是草稿批准。
- 用户可以回传修改后的完整草稿，也可以用 `草稿不做修改`、`这版没问题，锁定吧` 等无歧义语句批准当前完整草稿。
- 长镜头修订后同样必须再次确认。
- 详细设计完成后若要求合并，流程退回长镜头阶段，受影响镜头重新审批和设计。

## Seedance 2.0 输出契约

- 详细设计代码块固定保留 `参考<>中人物外观；参考<>场景氛围；参考<>道具。`。
- 每镜保持两个物理行，镜头设计和声音行各自为单行长描述，便于直接复制给 Seedance 2.0。
- 原文没有声音依据时不新增具体音效，使用“无新增音效，延续场景环境声”维持第二行结构。

## 开发验证
