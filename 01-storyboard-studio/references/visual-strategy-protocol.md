# 本场视觉策略协议

详细设计前，为每一场建立一份隐藏的“本场视觉策略”。它是整场选择的因果模型，不直接展示，也不是固定模板。

## 八维决策表

1. **锁定分镜节奏与景别**：从锁定草稿读取分镜节奏和景别曲线，逐镜冻结镜头顺序与景别；详细设计只核对是否原样保留，不重新评价或调整。
2. **机位逻辑**：机位高度只从 `眼高、腰高、膝高、贴地、高位` 选择，并为每个节拍确定俯仰与纵轴向方位角；明确它们如何改变信息、关系或主观性，建立全场纵轴向方位角变化路径。
3. **焦段与透视**：内部判断空间伸展、距离压缩、脸部透视、运动速度感与镜间匹配。默认不输出任何焦段、毫米数、广角透视或长焦压缩；只有用户明确要求时显示。
4. **运镜曲线**：在固定、摇移、推拉、前置/后置/侧向跟拍、手持观察之间建立稳定到变化的曲线。动作本身不等于必须运动。
5. **轴线系统**：标出关系轴、视线轴和运动轴；记录摄影侧、越轴动机与重建空间的方法。
6. **调度与权力**：跟踪人物距离、遮挡、高低、进入/退出、占据画面和权力变化；让机位响应调度，而不是替代表演。
7. **构图路径**：确定视觉焦点、视线进入顺序、留白、画框内画框、前景遮挡和负空间；只在镜头功能需要时写前中后景。
8. **影调与色彩**：锁定光源方向、明暗层级、色彩关系和时段连续性；把变化绑定到叙事节拍。

## 按可观察条件加载规则

- 始终读取景别、机位、调度和构图规则。
- 用户要求焦段，或场景存在明显透视、空间压缩、畸变与镜间透视匹配时，读取焦段规则。
- 用户要求运镜，或场景包含跟随、揭示、动作路径、失控与空间关系重构时，读取运镜规则。
- 场景包含两人以上关系、视线匹配、方向性运动或越轴风险时，读取轴线规则。
- 用户指定光色，或场景存在多光源、走位受光变化与跨镜光线连续性时，读取影调与色彩规则。
- 遇到例外、规则冲突或需要复核时，再读取对应 `visual-language/library/` 完整原文。

第一维是草稿阶段交付的不可变输入，不是详细阶段的设计自由度。若构图、机位、运镜或调度无法在锁定景别内成立，报告镜头 ID 并回到草稿阶段处理。

## 创作者方法映射

通用模式直接依据锁定草稿和已触发的视觉规则建立策略，不加载创作者资料。创作者模式读取主参考完整原文，把其中可用原则映射到本场具体节拍：哪条原则解决哪个叙事问题、影响哪一维、在哪些镜头生效、何时停止使用。不得用“冷色”“对称”“固定镜头”等少数标签代替整篇方法逻辑。

最多允许一个辅助参考，且必须由用户指定单一维度，例如只用于动作调度或只用于光影。辅助参考不得改变主参考控制整场的形式逻辑。

## 形式动机复核

- 每次运镜必须揭示信息、跟随路径、重构关系、改变心理距离或表现失控；没有功能就使用固定镜头。
- 重复使用同一机位高度、俯仰或纵轴向方位角可以成立，只检查它是否造成信息不可读、无意方向跳变或表演遮蔽。
- 不设固定镜头、机位高度或角度组合的比例阈值，不得为了数字多样性添加无功能形式。

## 运动术语

- 无运镜：写 `固定镜头`。
- 摄像机基本不移、但保留不稳定观察质感：写 `手持观察`。
- 摄像机随主体改变位置：写 `前置跟拍`、`后置跟拍` 或 `侧向跟拍`，并注明轨道、稳定器或手持质感。
- 摇、移、推、拉必须说明它揭示信息、改变距离、维持主体关系或表现失控的功能。
