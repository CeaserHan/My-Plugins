# 景别 (Shot Scale / Shot Size)

> **一句话核心**：景别量的是「主体占画幅的相对大小」，本质是一条**连续量**（以人占画幅的比例 / 等价的摄距为基准）。「分几种」是人为切分连续谱的问题，不是自然事实——刻度密度应由「这一级是否对应一个稳定可复用的叙事/构图功能」决定，而非追求穷尽。

---

## 一、SSOT：景别到底量的是什么

景别（shot scale）量的是**主体在画幅中占据的比例**，等价地也可用**摄距**表达。三个概念必须先分清，否则后面全乱：

| 概念 | 定义 | 关键点 |
|---|---|---|
| **景别** | 主体占画幅的相对大小 | **相对量**，不是绝对距离 |
| **摄距** | 相机到主体的物理距离 | 改变它 → 景别变 **+ 透视也变** |
| **焦距** | 镜头焦段（广角↔长焦） | 改变它 → 景别变 **但透视不变**（只是裁切/放大） |

**最重要的 SSOT 原则**：景别永远是「相对于谁」的景别。
同一画面，以人为基准是「全景」，以整栋楼为基准可能是「特写」。
→ **基准对象必须是 spec 里的显式字段，不能是隐含假设。**

**标准锚点**：站立的成年人。中文景别体系默认以人体作为刻度尺。

## 二、有多少种？——取决于颗粒度

不存在标准答案数字。主流三档切法：

| 切法 | 级数 | 内容 |
|---|---|---|
| **经典五分法**（学院派最小集） | 5 | 远景 · 全景 · 中景 · 近景 · 特写 |
| **七分法**（拍摄/分镜最常用） | 7 | 大远景 · 远景 · 全景 · 中景 · 近景 · 特写 · 大特写 |
| **九分法**（细颗粒） | 9 | 大远景 · 远景 · 全景 · 中全景 · 中景 · 中近景 · 近景 · 特写 · 大特写 |

再往下切能出十几档，但边界开始失去感知/叙事意义（切太细 = 增重不承载）。

## 三、完整景别体系（主表）

把中文十分法、英文体系、取景线、占比、功能全部对齐。从大到小：

| # | 中文名 | 英文名 / 缩写 | 人体取景线 | 人占画幅高度 | 核心功能 |
|---|---|---|---|---|---|
| 1 | **大远景 / 大全景** | Extreme Long Shot (ELS) | 人几乎是点，或看不见 | <10% | 交代宏观地理、环境规模、渺小感 |
| 2 | **远景** | Long / Wide Shot (LS/WS) | 全身 + 大量环境 | ~20–40% | 人物在环境中的位置关系 |
| 3 | **全景** | Full Shot (FS) | 头顶到脚，刚好框满 | ~70–90% | 完整肢体动作、走位、全身表演 |
| 4 | **中全景 / 七分身** | Medium Long Shot / Cowboy | 膝盖或大腿中段以上 | — | 动作 + 部分环境，对话常用起手 |
| 5 | **中景** | Medium Shot (MS) | 腰部以上 | — | 上半身表演 + 手势，最「中性」的叙事景别 |
| 6 | **中近景 / 半身** | Medium Close-Up (MCU) | 胸部以上 | — | 表情 + 少量肢体，对话主力景别 |
| 7 | **近景** | Close-Up (CU) | 肩膀 / 头肩以上 | — | 面部表情、情绪、心理 |
| 8 | **特写** | Close-Up / Big CU | 整张脸充满画面 | — | 强化情绪、聚焦细节 |
| 9 | **大特写** | Extreme Close-Up (ECU/XCU) | 局部：眼、嘴、手、物件 | — | 极端强调、抽象化、悬念 |

> ⚠️ **中英错位陷阱**：中文「特写」≠ 英文 Close-Up。
> 英文 **Close-Up** ≈ 中文「近景 + 特写」区间；英文 **Big Close-Up** 才对应中文纯「特写」。
> 做中英双语 spec 时这是必须**显式处理的映射**，否则模型/协作方理解会偏。

## 四、英文体系的独立逻辑：按「身体切线」命名

好莱坞不按「第几级」命名，而是**按画框底边切在人体的哪个部位**命名。更实操，直接告诉你「框到哪」：

| 英文名 | 画框底边切在 | 由来 / 备注 |
|---|---|---|
| Full Shot | 脚底（含全身） | — |
| **Cowboy / American Shot** | 大腿中段（约膝上） | 源自西部片——要露出腰间**枪套** |
| Medium Shot | 腰 | 最标准的对话景别 |
| Medium Close-Up | 胸 / 领口 | 电视访谈、双人对话最常用 |
| Close-Up | 肩 / 下巴上方 | — |
| Extreme Close-Up | 五官局部 | — |

> **Cowboy Shot 的启示**：景别的每一级往往是「功能倒逼」出来的——
> 不是先有刻度再找用途，而是某个叙事需求（露枪）稳定复用后，这一级才被固化命名。
> → 印证「刻度密度由功能决定」。

## 五、逐级叙事语义（导演层，真正 load-bearing）

取景线只是物理层，真正承重的是**每一级绑定的心理距离**：

| 景别档 | 心理距离 | 语义 |
|---|---|---|
| **大远景 / 远景** | 旁观者 | 人物被环境压制 → 孤独、渺小、宿命，或纯交代空间。开场镜（establishing）几乎都在此档 |
| **全景 / 中全景** | 社会距离 | 看得清人、看得清动作，但未入内心。展示行为、走位、空间关系 |
| **中景 / 中近景** | 个人距离 | 接近日常对话间距。叙事**默认档**，信息密度与情绪的平衡点，绝大多数戏在此展开 |
| **近景 / 特写** | 亲密距离 | 强迫观众进入内心看微表情。**越近 = 情绪权重越高 = 越不能滥用**（特写是感叹号，用多了贬值） |
| **大特写** | 抽象 / 象征 | 已脱离「看人」。一只发抖的手、一滴汗、一个转动的门把手。用于悬念、心理特写、蒙太奇节奏点 |

> **一句话记忆法**：景别越大 → 越「客观/叙事」；景别越小 → 越「主观/情绪」。
> 这条轴是调度情绪的**主旋钮**。

## 六、三个必须切开的易混维度（field-split 重点）

景别有三处最容易被 conflate，做 spec 必须拆成正交字段：

### ① 景别 ≠ 机位角度
景别管「多大」，角度管「从哪个高度/方向看」（俯/平/仰、正/侧/背）。
同一近景，可平拍可仰拍，语义完全不同。**必须是两个正交字段。**

### ② 同一景别，「退远用长焦」vs「走近用广角」，视觉完全相反
生成式视频里最容易塌的地方：

| 实现方式 | 景别 | 透视效果 |
|---|---|---|
| 广角 + 走近 | 特写 | 五官夸张、鼻子放大、空间被拉伸 |
| 长焦 + 退远 | 特写 | 面部压缩、背景虚化贴脸、「高级感」 |

**景别相同但透视相反** → 「景别」和「焦段/透视」必须是分开的两个字段。

### ③ 对人 / 对物 / 对景，景别基准要切换
「全景」对人是全身，对一辆车是整车，对一座城是整片天际线。
**基准对象是景别字段的必要前置声明**，不能默认。

## 七、景别的组接规律（剪辑/分镜层）

分类之外，景别之间的**跳跃关系**也有规则，直接影响分镜连贯性：

- **景别三角原则**：相邻镜头景别最好跨越 ≥1 级（中景→近景，别中景→中景），否则易出跳切感（jump cut）。同机位同景别相接 = 画面「抖一下」。
- **递进 vs 跳进**：一级级推近（全→中→近）= 平稳引导注意力；跨级猛推（远→特写）= 强冲击、强调。
- **匹配剪辑靠景别节奏**：一场戏的景别曲线本身就是情绪结构——
  - 先大后小 = 逐步进入内心
  - 先小后大 = 抽离 / 释放

## 八、实操映射

### 焦距 ↔ 景别粗略换算（35mm 全画幅，拍人）

| 焦段 | 典型景别 | 特征 |
|---|---|---|
| 14–24mm | 大远景 / 远景 | 广、透视强、畸变 |
| 35mm | 全景 / 中景 | 接近人眼、纪实感 |
| 50mm | 中景 / 中近景 | 标准、无畸变 |
| 85mm | 近景 / 特写 | 人像黄金焦段、压缩美 |
| 135mm+ | 特写 / 大特写 | 强压缩、背景奶化 |

### 生成式视频（即梦 / Seedance）提示词建议

景别应作为**独立提示词槽位**，与「镜头运动」「机位角度」「焦段透视」分开写。
模型对 `medium close-up, 85mm lens, eye-level` 这种正交拆分的响应，比一句混在一起的自然语言稳定得多。
→ **spec 里拆开的每一维，都要在提示词里保留独立表达槽位**，否则模型会替你做默认耦合，控制权就丢了。

## 九、景别进 spec 的字段结构

```yaml
shot_scale (景别):
  base_reference: 人 / 物 / 景        # 必填前置：相对于谁的景别（SSOT）
  tier: 大远景/远景/全景/中全景/中景/中近景/近景/特写/大特写
  en_mapping: ELS/LS/FS/MLS/MS/MCU/CU/BCU/ECU   # 中英映射，消歧用
  subject_ratio: <人占画幅高度>        # 可选，量化锚点
  narrative_function: <这一档为什么用它>  # 语义锚，不可穷举，需人写

  # —— 正交隔离（防 conflate）——
  # 以下三项不属于 shot_scale，单独立字段：
  #   camera_angle    → 机位角度（俯/平/仰、正/侧/背）
  #   focal_length    → 焦段/透视（广角拉伸 vs 长焦压缩）
  #   camera_motion   → 相机运动

  # —— 组接约束 ——
  cut_rule: 与相邻镜跨 ≥1 级           # 景别三角原则
```

`narrative_function` 是唯一不能穷举、必须人写的一维——
物理档位可枚举，功能回答「这一档为什么用它」，是防止景别沦为纯几何堆砌的 load-bearing 字段。

## 附：关联维度（本文档只覆盖景别，其余各自独立成文）

景别是视听语言空间维度之一，与以下维度**正交**（除标注联动者）：

- **机位高度**（相机多高，正交）
- **俯仰 / 朝向**（从哪看，正交）
- **轴线 / 越轴**（左右守恒，联动约束）
- **相机运动**（姿态随时间，部分联动）
- **焦段 / 焦距**（空间的形状，经摄距与景别**联动**）
- **OTS 正反打**（综合战场，景别在此需成对守恒）
