# 光影色调 (Lighting & Color)

> **一句话核心**：这是最「绘画」、最软的一维，拆成**光影（塑形/引导/情绪，生成时必须结构对、跨镜守恒）**和**色彩（情绪滤镜，纯下游、可后期 LUT 兜底）**两半。
> 它独有的特权：**别的维度错了得重生成，色彩错了能调色救。**

---

## 一、SSOT：光影色调量的是「光怎么落、颜色怎么配」

严格说这是**两个耦合但可分离的维度**，先切开：

| | 光影（Lighting） | 色调（Color / Tone） |
|---|---|---|
| 量的是 | 光从哪来、多硬、明暗差多大 | 画面的色相、饱和、色彩关系 |
| 塑造 | **形状、体积、空间、注意力** | **情绪、时代、心理、统一感** |
| 耦合点 | 色温（光的颜色）同时属两边 | 调色（grading）会重塑光影的明暗 |

**光影的三件核心工作**（它不是「照亮」，是塑形）：
1. **塑形（modeling）**——用明暗雕出主体的体积和质感，2D 画面里造 3D 立体。
2. **引导注意力**——亮的地方眼睛先去。光是最强的视觉重量分配器（接构图的视觉重量）。
3. **定情绪**——同一张脸，顶光=恐怖，正面柔光=温暖。光是情绪的物理载体。

**色调的核心工作**：给整部片一层**统一的情绪滤镜**，同时用色彩关系制造对比、引导、象征。

> 这两半是整套体系里**最「软」的维度**——景别机位是几何、可精确参数化；光影色调更接近绘画，是连续的、感性的。但仍可 field-split。

# ▊ 光影（Lighting）

## 二、光的方向——最有塑形力的一维

光从哪个方位打来，决定主体的明暗分布。塑形语义最强（类比机位的俯仰）：

| 光位 | 英文 | 光从哪来 | 塑形/语义 |
|---|---|---|---|
| **正面光 / 顺光** | Front / Flat | 镜头方向打向主体 | 平、无阴影、无体积；证件照感、也可清新/无辜 |
| **侧光** | Side | 90° 侧向 | **最强塑形**，一半亮一半暗，立体、戏剧、性格 |
| **前侧光（45°）** | Three-quarter | 斜前方 45° | **人像标准光**，有体积又不过暗，自然悦目 |
| **逆光 / 背光** | Back / Rim | 主体后方打来 | 勾出**轮廓光**、分离主体与背景、剪影、神圣/唯美 |
| **顶光** | Top | 正上方下打 | 眼窝鼻下成阴影，压抑、审讯、非人、恐怖 |
| **底光 / 脚光** | Under / Uplight | 下方上打 | 违反自然（光通常从上），怪诞、恐怖、鬼魅 |
| **边缘光 / 侧逆光** | Kicker / Edge | 侧后方 | 勾边、增质感、把主体从暗背景里「提」出来 |

> **一句话记忆**：光越贴正面越平、越侧越立体、越从下/顶越怪。前侧 45° 是安全悦目区，顶光底光是恐怖区。

> **光位是空间事实——跨镜头不能翻。** 正反打两镜光源方向必须一致（光从画面左来，反打里还得从左来），否则两人像处在两个不同空间。
> **光影方向是继轴线、焦段之后，第三个必须镜像守恒的维度**（接 OTS 文档）。

---

## 三、光质：硬光 vs 柔光——影子的边缘

同一光位，光「硬」还是「软」性格完全不同。由**光源相对主体的大小**决定（越大越柔）：

| | 硬光（Hard） | 柔光（Soft） |
|---|---|---|
| 光源 | 小而远（裸灯、正午太阳、点光源） | 大而近（柔光箱、阴天、反光） |
| 影子 | 边缘锐利、深、明确 | 边缘羽化、浅、朦胧 |
| 质感 | 强调纹理（皱纹、粗糙） | 抹平纹理（磨皮、柔美） |
| 语义 | 硬朗、残酷、纪实、紧张、男性化 | 温柔、梦幻、美化、亲密、女性化 |

> **光质和光位正交**——任何光位都能硬能软。侧硬光=硬汉/黑色电影；侧柔光=优雅人像。两个独立字段。

---

## 四、三点布光与光比——布光的语法

经典布光结构，理解它就理解了绝大多数画面的光怎么搭：

| 灯 | 英文 | 作用 |
|---|---|---|
| **主光** | Key | 主导光源，定光位和基本明暗 |
| **辅光** | Fill | 填暗部，控制明暗反差，从主光对侧补 |
| **背光/轮廓光** | Back / Rim | 从后方勾边，分离主体与背景 |

**光比（Lighting Ratio）= 主光侧亮度 : 辅光侧亮度**，情绪的核心旋钮：

| 光比 | 明暗反差 | 语义 |
|---|---|---|
| 低光比（1:1–2:1） | 平、暗部也亮 | 明快、日常、喜剧、访谈 |
| 中光比（4:1） | 有立体、暗部还有细节 | 标准叙事 |
| 高光比（8:1+） | 强反差、暗部死黑 | 戏剧、悬疑、黑色电影、危险 |

> **光比是「光影版的对比度」**——低光比松弛，高光比紧张。调这一个数，情绪就变。

---

## 五、影调：高调 vs 低调——整个画面的明暗基调

不是单个主体，是**整幅画面的明暗分布倾向**：

| 影调 | 英文 | 画面 | 语义 |
|---|---|---|---|
| **高调** | High-key | 整体明亮、阴影少、低反差 | 明快、纯净、梦幻、喜剧、广告、未来感 |
| **低调** | Low-key | 整体暗、大片阴影、高反差、少量亮部 | 压抑、神秘、危险、黑色电影、恐怖 |
| **中间调** | Mid-key | 均衡 | 大多数写实叙事 |

> 高调低调是**全片/全场级基调决策**（跨镜头一致性约束），不是逐镜自由项——类似焦段基调、构图基调。

---

## 六、光的动机（Motivation）——光影的 load-bearing 字段

**每一处光都该有来源解释**，区分专业布光和「打亮就行」的关键：

| | 有源光（Motivated） | 无源光（Unmotivated） |
|---|---|---|
| 定义 | 画面里能找到光源（窗、灯、火、月） | 为效果而打，没有叙事来源 |
| 效果 | 可信、沉浸、写实 | 若无意为之=穿帮；若风格化=表现主义 |

**光的动机决定风格光谱**：
- **写实主义布光**：光都有源，模拟真实光环境（现实题材、纪录感）。
- **表现主义布光**：光服务情绪而非物理真实（黑色电影的百叶窗光、恐怖片的底光）。

> `motivation` 是光影里必须人写、不可穷举的一维——回答「这束光为什么存在」。和运镜的动机、调度的 business 是同一类 load-bearing 字段：**没有动机的布光，就是打亮而已。**

---

## 七、人像光型（Portrait Patterns）——脸部布光的固定语汇

拍脸时主光位置的经典型，各有名字和性格（做角色近景/特写时直接调用）：

| 光型 | 特征 | 语义 |
|---|---|---|
| **伦勃朗光** | 暗侧脸颊有一个倒三角亮斑 | 经典、深沉、艺术、性格 |
| **蝴蝶光 / 派拉蒙光** | 正前偏上，鼻下有蝴蝶状阴影 | 魅力、优雅、老好莱坞女星 |
| **分割光 / 阴阳光** | 正侧，脸一半全亮一半全暗 | 冲突、双面、戏剧、危险 |
| **环形光** | 前侧略高，鼻侧一小段影 | 自然、通用、大多数人像 |
| **轮廓光 / 剪影** | 只有逆光勾边，脸黑 | 神秘、匿名、有力 |

# ▊ 色调（Color / Tone）

## 八、色温——暖 vs 冷

画面整体偏暖（橙黄红）还是偏冷（蓝青），色调最基础的一维：

| | 暖色调 | 冷色调 |
|---|---|---|
| 色相 | 橙、黄、红 | 蓝、青、绿 |
| 心理 | 温暖、亲密、怀旧、活力、危险(火) | 冷漠、孤独、理性、科技、平静、死亡 |
| 常见用途 | 回忆、家庭、日落、爱 | 科幻、悬疑、医院、夜、疏离 |

> **暖冷对比**是最常用的色彩戏剧手法——**橙蓝对比（teal & orange）**是好莱坞商业片标志配色：肤色偏暖、阴影/背景偏冷，主体从背景里「跳」出来。用滥了，但有效。

---

## 九、饱和度与明度——颜色的「音量」

| 维度 | 高 | 低 |
|---|---|---|
| **饱和度** | 鲜艳、浓烈、超现实、活力、童趣 | 灰、褪色、压抑、写实、高级、末世 |
| **明度** | 明亮、轻快 | 暗沉、沉重 |

> **降饱和**是当代剧情片常见选择（「高级灰」），**高饱和**是幻想/童话/复古标志。
> 这一维和影调（明暗）正交——可又暗又饱和（浓郁夜景），也可又亮又低饱和（惨白日光）。

---

## 十、色彩关系（Color Harmony）——颜色怎么搭

不是单个颜色，是**颜色之间的关系**（借自色轮）：

| 配色 | 关系 | 效果 |
|---|---|---|
| **单色** | 同色相不同明度 | 统一、极简、情绪纯粹 |
| **类似色** | 色轮相邻 | 和谐、舒适、自然 |
| **互补色** | 色轮对冲（橙蓝、红绿） | 强对比、张力、活力 |
| **分裂互补 / 三角** | 更复杂的对冲 | 丰富但需控制 |

> **色彩对比也是注意力工具**：画面整体低饱和，一个红色物体=绝对焦点（《辛德勒名单》红衣女孩）。
> **孤立的一抹强色 = 构图焦点的化学增强剂**，直接接构图的视觉引导。

---

## 十一、色彩心理与色彩脚本（Color Script）

**色彩语义**（有文化差异，非绝对）：红=激情/危险/血；蓝=忧郁/冷静/科技；绿=自然/病态/嫉妒；黄=希望/疯狂/警示；紫=神秘/高贵。

**色彩脚本（Color Script）**——皮克斯发明的工具，把整部片的色彩情绪画成一条**时间线上的色带**：每场戏用什么主色调，随剧情起伏。它让色彩成为**结构性叙事工具**而非逐镜装饰。

> 对你：色彩脚本本质上就是**色调版的「距离曲线/beat 对齐」**——把色调决策从「这镜好看」提升到「整部片的情绪结构」。一场戏的色调不是孤立选的，是色带上的一个点。

---

## 十二、调色 / Color Grading——后期的色彩重塑

拍摄/生成得到的是「素材色」，**调色**在后期重塑最终 look：

- **一级调色**：校正曝光、白平衡、对比（把素材调「对」）。
- **二级调色**：局部调、换色、加 LUT、定 look（把素材调「美/统一」）。
- **LUT / Look**：一套预设的色彩映射，给全片盖统一色彩风格。

> **调色是这套体系里唯一「纯下游、纯后期」的部分**——不改变拍到什么，只改变最终呈现的色彩。这一点对生成式极其关键（下节）。

# ▊ 生成式落地

## 十三、光影色调在生成式里：MJ 的主场，但一致性是天坑

**单帧质量最高，跨镜头一致性最差，但有后期救赎。**

**① 光影色调是 MJ 最擅长的东西。**
MidJourney 对光影和氛围的理解是它最强的能力——`rembrandt lighting, low-key, teal and orange, volumetric light` 响应极好，出图的光影质感常超过描述。**你的 MJ 首帧天然就是光影色调的控制器**，和它锁构图是同一张图的两个作用面。

**② 但跨镜头光影一致性是最大天坑。**
每个 clip 独立生成 → 每镜的光位、光比、色温都可能不同。典型崩坏：
- 正打暖光从左来，反打冷光从右来——两人像不在同一场景（违反光影镜像守恒）。
- 同场戏 A 镜低调、B 镜突然高调，情绪断裂。
- 角色脸上的光型逐镜漂移。

> 光影一致性比构图一致性更难守，因为它是**弥漫全画面的属性**，不像构图能靠首帧位置钉死。

**③ 对策——三层防线**：

| 层 | 手段 | 作用 |
|---|---|---|
| **全场声明** | brief 里定死影调基调（低调/暖调/橙蓝）+ 光源方位 | 跨镜一致性约束，每镜继承 |
| **首帧锁定** | MJ 首帧把光位、光比、色温排好，Seedance 继承 | 单镜锁定 |
| **后期统一（杀手锏）** | DaVinci 里上统一 LUT / 调色，把逐镜色差抹平 | **生成式独有的救赎** |

> **第三层是关键洞察**：调色纯后期、纯下游，**色调的最终一致性不必在生成阶段解决，可留到调色阶段统一**。生成时只要光影结构大致对，色温/饱和/对比的最终统一交给一条全片 LUT——生成式管线里**最省力的一致性保险**。
> **光影结构（方向/光比）必须在生成时对，但色彩层可以后期兜底。**

**④ 光影用 Blender previs 能锁结构。**
Blender 里可摆光源、定光位——clay 渲染虽非最终质感，但**光的方向和明暗结构**能作为参考传下去。这是 previs 在光影维度的价值：锁「光从哪来」，而非锁最终色彩。

## 十四、这一维的归属：双重身份

在依赖图里位置微妙：

```
光影结构（光位/光比/影调）
  ├─ 概念上属调度（mise-en-scène，在 3D 世界里）
  ├─ 实践中靠首帧锁死（像构图，单帧 look 属性）
  └─ 光位是空间事实 → 跨镜守恒（像轴线/焦段）

色彩层（色温/饱和/grade）
  └─ 纯下游、纯后期 → 可后期统一（唯一能"事后补救"的维度）
```

**结论**：光影是**「上游构思、首帧锁定、跨镜守恒」**三重身份的混合体；色彩是**纯下游、可后期兜底**。
所以 spec 里，光影应挂靠调度/首帧，色彩应单列一个「可后期」标记——这是它区别于所有其他维度的特权：**别的维度错了要重生成，色彩错了可以调色救。**

## 十五、落地：光影色调进 spec 的字段结构

```yaml
light_and_color (光影色调):
  # —— 光影（结构，生成时必须对）——
  lighting:
    direction: 正面/侧/前侧45/逆/顶/底/边缘   # 光位，空间事实，跨镜守恒
    quality: 硬光 / 柔光                      # 光质，与光位正交
    ratio: 低(1:1) / 中(4:1) / 高(8:1+)       # 光比=情绪旋钮
    tonal_key: 高调 / 低调 / 中间调           # 全场基调
    portrait_pattern: 伦勃朗/蝴蝶/分割/环形/轮廓  # 脸部光型（近景用）
    motivation: <这束光的来源/为什么存在>       # load-bearing，需人写
    mirror_lock: true                        # 正反打光源方向必须一致
  # —— 色彩（look，可后期兜底）——
  color:
    temperature: 暖 / 冷 / 中性
    saturation: 高 / 中 / 低
    harmony: 单色/类似/互补(橙蓝)/三角
    accent_color: <孤立强色，做焦点用>         # 接构图视觉引导
    color_script_point: <本场在全片色带上的位置>  # 色调版 beat 对齐
  # —— 一致性与执行 ——
  scene_consistency: <全场影调/色调基调>        # 跨镜约束，每镜继承
  control_tier: 首帧（光影结构）/ 后期LUT（色彩统一）
  keyframe_ref: <MJ 首帧，锁光影质感>
  previs_light_ref: <Blender 光位参考，可选>
  post_gradeable: true                        # 色彩层可后期救，光影结构不可
```

**load-bearing 字段**：
- `motivation`——光影的动机锚，防止「打亮就行」。
- `mirror_lock`——光位跨镜守恒的显式开关，接 OTS。
- `post_gradeable`——这一维的特权标记：告诉管线「色彩可留到后期统一，别在生成阶段死磕色差」。**这是光影色调独有的、能省大量返工的一格。**

---

**一句话收束**：光影色调是最「绘画」、最软的一维，拆成**光影（塑形/引导/情绪，生成时必须结构对、跨镜守恒）**和**色彩（情绪滤镜，纯下游、可后期 LUT 兜底）**两半。它在生成式里是 MJ 的主场（单帧质感极强），但跨镜一致性是天坑——解法是「全场声明 + 首帧锁光影结构 + 后期 LUT 统一色彩」三层防线。它独有的特权：**别的维度错了得重生成，色彩错了能调色救。**

## 附：关联维度

- **调度（上游）**：光影结构概念上属 mise-en-scène；光位是 3D 空间事实
- **构图**：光=最强的视觉重量分配器（亮处先看）；孤立强色=构图焦点增强
- **焦段 / 景深**：浅景深的虚化层 + 光影暗部，共同引导注意力
- **轴线 / OTS**：光源方向是继轴线、焦段之后第三个跨镜镜像守恒的维度
- **人物近景**：人像光型（伦勃朗/蝴蝶等）在近景/特写直接调用
- **后期 / 剪辑**：色彩层是唯一可在调色阶段统一兜底的维度（post_gradeable）
