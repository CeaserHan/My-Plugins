# 机位 (Camera Setup)

> **一句话核心**：机位的完整姿态 = 刚体 6DOF（XYZ 位置 + Pan/Tilt/Roll 朝向）。
> 本文档把机位收敛为四维：**位置轴的高度（Y）** 与 **朝向轴（俯仰 Tilt + 水平朝向 Pan + 横滚 Roll）**。
> 核心区分贯穿全篇：**高度决定「相机站哪」，朝向决定「相机往哪看」——二者正交，可任意组合。**

---

## 零、先定位：这几维在 6DOF 里的位置

| 轴类别 | 具体轴 | 控制什么 | 本文档 |
|---|---|---|---|
| 平移（位置） | X 左右 | 相机站左/中/右 | ✗（另属方位/越轴） |
| | Y 上下 | **相机的高度** | ✅ 第一部分 |
| | Z 前后 | 摄距 → 决定景别 | ✗（已由景别字段接管） |
| 旋转（朝向） | Pan 水平摇 | **镜头水平指向**（正/侧/背） | ✅ 第三部分 |
| | Tilt 垂直摇 | **镜头俯仰**（俯/平/仰） | ✅ 第二部分 |
| | Roll 横滚 | **地平线倾斜**（荷兰角） | ✅ 第四部分 |
| 语义 | 视点归属 | 这台相机是「谁的眼睛」 | ✗（另属视点字段） |

> **field-split 提醒**：Z 轴（前后）已被「景别」字段单独接管，所以机位的位置轴在 spec 里**只保留 X + Y**，避免和景别打架。本文只谈 Y。

> **本插件生产词表**：详细分镜的高度统一收敛为 `眼高、腰高、膝高、贴地、高位`；绕垂直轴观察主体的方向统一称为 `纵轴向方位角`，写成 `纵轴向正视 / 侧视 / 左右四分之三侧 / 背面 / 左右后四分之三侧`。这是给 Seedance 2.0 的独立表达槽位，不改变下文 6DOF 原理。下文肩高/胸高在成品中归入眼高，航拍/顶置归入高位，地面/地穴归入贴地；非常规程度写进画面关系，不新增高度档位。

# 第一部分：机位高度（Height / Y 轴）

## 一、SSOT：机位高度 ≠ 俯仰角度

这是两个正交自由度，被混用是因为它们经常**耦合出现**，但可以独立取值：

| | 机位高度 | 俯仰角度（Tilt） |
|---|---|---|
| 定义 | 相机**在空间里的 Y 坐标**（离地多高） | 镜头**光轴相对水平线的倾角**（往上/往下指） |
| 变量 | 相机放在哪个海拔 | 镜头朝哪偏 |
| 6DOF 归属 | 平移 Y | 旋转 Tilt |

**证明它们独立的关键例子**：
相机架在 3 米高，但镜头**平着**指向远处 3 米高的窗户 → **高机位 + 平视角**，画面里没有任何俯视感。
反过来，相机在地面、镜头**往上仰** → 低机位 + 仰角。

→ **高度决定相机站哪，俯仰决定它往哪看，二者可任意组合。**
在 spec 里必须是两个字段：`height_y`（位置）和 `vertical_angle`（朝向）。

---

## 二、机位高度完整档位

以**站立成年人的眼睛**为 0 基准，从高到低：

| 高度档 | 英文 | 相机 Y 位置 | 典型配合的俯仰 | 独立语义（仅高度贡献） |
|---|---|---|---|---|
| **航拍 / 顶置** | Aerial / Overhead | 数米～数十米以上 | 常配大俯或垂直下视 | 宏观、抽离、地理尺度 |
| **高机位** | High setup | 明显高于人（登高、摇臂） | 常配俯视 | 俯瞰空间、掌控全局的观察位 |
| **肩高 / 胸高** | Shoulder / Chest | 约 1.3–1.5m | 多配平视 | 略高于常规、稳重 |
| **眼平** | Eye-level | ≈ 1.5–1.7m，与人眼齐 | 平视 | **中性基准**、日常、代入 |
| **腰高 / 髋高** | Hip / Waist | 约 0.9–1.1m | 常配轻微仰视 | 经典好莱坞对话高度、稳定、微仰人物 |
| **膝高** | Knee | 约 0.5m | 常配仰视 | 动作片常用、突出下肢动作、力量感 |
| **地面 / 低机位** | Low / Ground | 贴近地面 | 常配大仰 | 压迫、异化、让主体高耸 |
| **地穴 / 埋地** | Sub-level / Buried | 低于地平面 | 极端上仰 | 极端仰视、非人视角、超现实 |

## 三、高度「单独」贡献了什么（剥离俯仰后）

最容易被吃掉的部分。假设**俯仰恒定为平视**，只动高度，画面仍会变——这才是高度独立的 load-bearing 价值：

**① 视平线在画框里的位置变了。**
高机位平视 → 地平线偏画面上方，地面占比大，人物「踩在大片地上」；
低机位平视 → 地平线偏下，人物顶着大片天/背景。
直接改变构图重心，与俯仰无关。

**② 观众的「身位代入」变了。**
眼平 = 成人视角；膝高 = **儿童 / 宠物 / 匍匐者的身位**。
经典手法：拍小孩戏把相机降到孩子眼高，哪怕平视，观众也会本能地「变矮」。这是高度独占的代入效应。

**③ 前景遮挡关系变了。**
低机位会让地面前景物（草、桌沿、人群的头）挡进画框下缘；高机位则俯瞰式清空前景。这是空间信息量的差异。

> **一句话**：俯仰改变「你如何评价主体」，高度改变「你站在谁的身位、地平线切在哪」。两者叠加才是完整视角。

## 四、高度 × 俯仰 组合矩阵（把正交性讲透）

九种组合各有独立语义，证明它们真是两个维度：

| | 平视 | 仰角 | 俯角 |
|---|---|---|---|
| **高机位** | 高处平望（站阳台看对面同高的人） | 罕见、别扭（高处还往上看天） | **经典大俯**，全景俯瞰 |
| **眼平** | **标准中性镜** | 站原地抬头看高个/高楼 | 站原地低头看矮者/地面物 |
| **低机位** | 蹲下平视（孩子身位） | **经典英雄仰拍**，主体高耸 | 罕见、别扭（趴地还往下看） |

- **对角线**（高机位+俯 / 低机位+仰）= 最常见的「自然耦合」，也是二者容易被误当成一个维度的原因。
- **反常组合**（高机位+仰、低机位+俯）= 风格化调度的富矿，因为打破了观众的直觉预期。

# 第二部分：俯仰角度（Tilt 轴）

相机相对主体的高低视角。机位里**心理语义最强**的一维：

| 角度 | 英文 | 相机指向 | 心理语义 |
|---|---|---|---|
| **顶视 / 鸟瞰** | Bird's-eye / Overhead | 正上方 90° 俯视 | 上帝视角、命运感、图案化、彻底抽离 |
| **大俯** | High angle (extreme) | 高处明显下压 | 渺小、脆弱、被压制、被审视 |
| **俯拍** | High angle | 略高于视线 | 弱势、客观交代空间 |
| **平视** | Eye-level | 与主体眼睛齐平 | 中性、平等、代入、日常 |
| **仰拍** | Low angle | 略低于视线 | 强势、威严、高大 |
| **大仰** | Low angle (extreme) | 明显低处上仰 | 压迫感、英雄化、恐惧化 |
| **虫视** | Worm's-eye | 贴地往上 | 极端仰视、异化、非人视角 |

> **一句话记忆**：俯拍贬低、仰拍抬高、平视对等。
> 这条轴是操控「观众如何评价这个人物」的主旋钮，比台词更底层。

---

# 第三部分：纵轴向方位角（Pan 轴 / 绕主体方位）

相机绕主体水平旋转的方位（同时耦合 X 轴——相机绕到主体哪一侧）：

| 方位 | 英文 | 看到主体的 | 语义 |
|---|---|---|---|
| **正面** | Front / Frontal | 完整面孔，直视 | 直接、对峙、坦诚，也可能审问感 |
| **四分之三前侧** | Three-quarter front | 面部 3/4 + 立体感 | **最常用**，自然、有体积 |
| **正侧** | Profile | 完整侧脸剪影 | 客观、疏离、「旁观一段关系」 |
| **四分之三后侧** | Three-quarter back | 后脑 + 一点脸颊 | 悬念、跟随、未完全揭示 |
| **背面** | Back / Rear | 只有背影 | 神秘、离去、拒绝、代入其「前方视野」 |

> **正面 ↔ 背面这条轴控制的是「揭示程度」**——给观众看多少这个人的脸，就等于给多少信息和亲近感。

---

# 第四部分：横滚（Roll 轴 / 荷兰角）

经常被漏掉的一维，因为它平时恒等于 0（地平线水平）。但它是**独立自由度**：

**荷兰角（Dutch angle / Canted angle）**——把地平线倾斜。
语义：**失衡、眩晕、不安、精神异常、世界出错了。**
它不改变俯仰和方位，只是把整个画框转一个角度。

> 因为它独立于俯仰轴，spec 里必须是**单独字段**，不能塞进「垂直角度」里——又一处该 field-split 的点。

## 落地：进 spec 的字段结构

```yaml
camera_setup (机位静态姿态，本文覆盖部分):
  position:
    # horizontal_x → 另属方位/越轴字段，此处略
    height_y:                          # 机位高度，独立于俯仰
      档位: 航拍/高机位/肩胸高/眼平/腰髋高/膝高/低机位/地穴
      基准: 站立成人眼高 = 0
      单独语义: 视平线位置 + 身位代入 + 前景遮挡
  orientation:
    vertical_angle:                    # 俯仰 Tilt，独立于高度
      档位: 顶视/大俯/俯/平/仰/大仰/虫视
      单独语义: 主体的心理评价（贬低↔抬高）
    horizontal_facing:                 # 水平朝向 Pan
      档位: 正面/前侧/正侧/后侧/背面
      单独语义: 揭示程度（给观众看多少脸）
    roll:                              # 横滚，独立字段
      档位: 水平 / 荷兰角 ±N°
      单独语义: 失衡/眩晕/精神异常
  # narrative_function → 语义锚，回答「这个机位为什么存在」，需人写
```

## 生成式视频（即梦 / Seedance）提示词建议

**高度和俯仰要用两个独立词组表达，别合并。**
例如要「低机位但平视」：写 `low camera position, eye-level angle`。
如果只写 `low angle`，模型会默认把高度和仰角绑死，你就永远拿不到「低机位平视」这种解耦画面。

> **核心原则**：你 spec 里拆开的每一维，都要在提示词里保留独立表达槽位——
> 否则模型会替你做默认耦合，控制权就丢了。
> 高度（位置词）/ 俯仰（angle 词）/ 朝向（front/profile/back 词）/ 荷兰角（canted/dutch）各自独立下词。
