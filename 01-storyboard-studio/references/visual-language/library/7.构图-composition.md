# 构图 (Composition)

> **一句话核心**：前面维度都在描述「相机在 3D 空间里的状态」，构图描述的是**这些决定之后，元素在 2D 画框上如何排布、眼睛往哪走**。
> 它是「3D 场景 → 2D 画框」这一步的作者决策层，终极功能是**替观众设计眼睛的动线**。

---

## 一、SSOT：构图量的是「2D 画面平面上的排布」

构图（composition）不描述相机在哪、主体多大，而描述——**当那些都定了之后，画框这个矩形里各元素落在什么位置、视觉重量怎么分配、眼睛按什么路径移动**。

和前面所有维度切开：

| 维度 | 作用空间 | 回答 |
|---|---|---|
| 景别 | 3D | 主体占画幅多大 |
| 机位 | 3D | 相机站哪、往哪看 |
| 焦段 | 3D | 空间被拉伸还是压缩 |
| 运镜 | 3D×时间 | 姿态如何随时间变 |
| 调度 | 3D（上游） | 世界怎么编排 |
| 轴线 | 组接 | 左右方位守恒 |
| **构图** | **2D 画面** | **元素在这块矩形里怎么摆、眼睛往哪走** |

### 构图的双重性

- 一部分**被上游决定**——景别、焦段、机位、调度一旦定了，画面里「有什么、多大、什么透视、分几层」就锁死了。
- 一部分是**独立决策**——在给定景别下，主体**具体放在矩形哪个位置**、留白留哪边、地平线切哪、视线动线怎么排，这些是构图自己的自由度。

> 构图 = **上游 3D 决策收敛到 2D 后，剩下的画面平面排布权**。不是「另一个 3D 维度」，是「2D 排布层」。它是下游——大部分内容继承自调度/景别/焦段。

**构图本身也多维**，下面逐一 field-split：画框 · 分区 · 平衡 · 呼吸空间 · 线条 · 视觉引导。

---

## 二、画框 / 画幅（Frame / Aspect Ratio）——先定这块矩形的形状

一切构图发生在画框内，画框比例是前置约束：

| 画幅 | 比例 | 性格 | 典型用途 |
|---|---|---|---|
| **学院比 / 标准** | 1.33:1 (4:3) | 方正、经典、聚焦人物 | 老电影、复古 |
| **宽银幕** | 1.85:1 | 主流剧情片 | 影院标准叙事 |
| **变形宽银幕** | 2.39:1 (Cinemascope) | 极宽、史诗、留白多 | 西部、科幻、风景 |
| **数字标准** | 16:9 (1.78:1) | 电视/流媒体默认 | 绝大多数视频 |
| **竖屏** | 9:16 | 垂直、贴脸、单主体 | 手机/短视频/社媒 |
| **方形** | 1:1 | 对称、中心化 | 社媒、实验 |

**画幅怎么影响构图**：越宽 → 横向留白/多主体并置余地越大，单人易「孤立在两侧空旷」；越竖 → 强制单主体、纵向堆叠、贴近感强。
> **竖屏和横屏是两套构图逻辑**——三分法、留白、多人同框规则全要重写。对短视频管线是硬约束。

---

## 三、分区系统 / 构图法则——主体放画框哪里

「元素放哪」的经典解法。不是规则，是**放置注意力的工具**：

| 构图法 | 做法 | 语义 / 效果 |
|---|---|---|
| **三分法** | 横竖各三等分，主体/视平线放分割线或交点 | 最通用、自然、不呆板。默认起手 |
| **中心构图** | 主体正中 | 稳定、对峙、仪式感、被凝视。用好=强，用不好=呆板 |
| **对称构图** | 左右/上下镜像 | 秩序、庄重、宿命、控制感 |
| **黄金分割 / 螺旋** | 主体沿黄金螺旋收束点 | 比三分法更「精致」，视线自然被卷入 |
| **对角线构图** | 主元素沿对角线排布 | 动感、不稳定、张力、引导纵深 |
| **框架式构图** | 用门/窗/前景物框住主体 | 窥视、层次、聚焦、把观众「关在外面」 |
| **引导线构图** | 用道路/栏杆/光线把视线引向主体 | 强制视线路径、强调纵深 |
| **三角形构图** | 元素构成三角/金字塔 | 稳定、group shot 主力、古典 |

**实操要点**：一个画面往往**叠加多种**（三分法定位 + 引导线指向 + 框架式加层次）。构图法是叠加的注意力工程，不是单选。
> **中心 vs 三分**是最基础的一次决策：要「稳定/对峙/仪式」→ 中心；要「自然/呼吸/叙事」→ 三分。

## 四、视觉重量与平衡（Visual Weight & Balance）

构图的底层物理：每个元素都有「视觉重量」，构图就是**在矩形里分配和平衡这些重量**。

**什么增加视觉重量**（由重到轻的直觉）：

| 因素 | 更重 |
|---|---|
| 大小 | 越大越重 |
| 位置 | 越靠边/越孤立越重（杠杆效应） |
| 对比/明度 | 越亮、对比越强越重 |
| 色彩 | 暖色、饱和色更重 |
| **人脸/眼睛** | **最重**——人眼永远先找脸 |
| 清晰度 | 实焦比虚焦重 |
| 运动/朝向 | 动的、指向性强的更重 |

**两种平衡**：
- **对称平衡**——左右重量相等 → 稳定、正式、静态（可能呆板）。
- **非对称平衡**——不同元素相互制衡（大而近 vs 小而亮）→ 动态、自然、有张力。更高级的常态。

**留白 / 负空间（Negative Space）**——不是「空」，是构图元素。大面积留白 → 孤独、渺小、呼吸、聚焦。留白的方向和大小是主动决策，不是「没填满」。

## 五、画框内的呼吸空间（三种 Room）——轴线在 2D 的投影

这一节和轴线/OTS 直接咬合，最实操：

| 空间 | 英文 | 规则 | 违反后果 |
|---|---|---|---|
| **头顶空间** | Headroom | 头顶留适度空隙，不多不少 | 太多=人下沉、空洞；太少=压抑、憋 |
| **视线空间 / 鼻前空间** | Looking / Nose room | 人物**看向的那一侧**留更多空间 | 不留=视线「撞墙」、憋闷、不安 |
| **前置空间 / 运动空间** | Lead room | 人物**运动方向的前方**留更多空间 | 不留=像要撞出画、被逼到边缘 |

**看向哪、走向哪，就在那一边留空间**——构图铁律。
> 这也是**为什么正反打的留白方向天然相反**（A 看右留右空间，反打 B 看左留左空间）。
> looking room 的方向由视线轴线决定 → **构图的呼吸空间是轴线在 2D 画面上的直接投影**。做 OTS 配对时，「后景那张脸看向哪、留白留哪」就是这条规则在管。

## 六、线条与地平线（纯 2D 的方向性）

> **注意**：前中后景**纵深层次**已归**调度**（因在 3D 空间摆位，果才是 2D 显影）——见 `blocking.md` §三。
> 构图只**继承**其 2D 投影结果，本节不含分层，只留纯 2D 的线条与地平线。

**线条的情绪**（画面里的隐性/显性线条）：

| 线条 | 情绪 |
|---|---|
| 水平线 | 平静、稳定、开阔 |
| 垂直线 | 力量、庄严、静止 |
| 对角线 | 动感、张力、不稳定 |
| 曲线 / S 线 | 优雅、流动、柔和 |
| 汇聚线 | 纵深、引导、透视 |

**地平线位置**是最常用的线条决策：
- 压低（天空多）= 开阔/渺小/自由
- 抬高（地面多）= 压迫/扎实/信息密集

> 地平线在画框的高低，同时受**机位高度**联动（高机位平视→地平线偏上）——构图在此继承机位维度的决策。

---

## 七、视觉引导（Focal Point & Eye Path）——构图的最终目的

前面全是手段，目的只有一个：**控制观众眼睛先看哪、按什么路径看、最后停哪**。

- **视觉中心（Focal Point）**：眼睛最先、最终落脚的点。构图所有工具（重量、引导线、对比、虚实）都在**制造和保护这个焦点**。
- **视线路径（Eye Path）**：眼睛在画面里移动的轨迹。好构图设计这条路径（沿引导线进入 → 到主体 → 被留白引导出画）。
- **单一 vs 多焦点**：一个清晰焦点=明确有力；多焦点=丰富但可能混乱（群戏靠层次和引导排出「先看谁」，这部分与调度的群戏焦点管理耦合，见 `blocking.md` §十四）。

> **一句话**：构图 = **用画面元素的排布，替观众决定「眼睛的动线」**。别的维度决定「拍到什么」，构图决定「怎么看」。

## 八、生成式视频语境：构图是最该、也最能用首帧锁死的维度

**构图在生成式里的地位和运动正好相反**：

| | 运动（最难控） | 构图（最好控） |
|---|---|---|
| 性质 | 跨帧的几何变化序列 | **单帧的 2D 排布** |
| 文字可控性 | 极弱 | 中等（法则名词模型懂） |
| **图控可控性** | 需视频参考轨迹 | **一张首帧图 100% 锁死** |

**核心洞察**：构图是**单帧属性**——完全活在第一帧里。所以：

**① 构图 = 首帧的职责，几乎不靠提示词。**
你的 **MidJourney 关键帧本质上就是构图控制器**。用 MJ 出一张主体在三分点、有前景框架、留白在看向一侧的图，构图就**完整钉死**了。Seedance 拿这张首帧，构图被继承，模型不需「理解」你的构图意图——它照抄。
> 这是 MJ→Seedance 管线里**控制力最强、最干净**的一环。构图不是「祈祷模型排得好」，是「上游 MJ 排好、下游继承」——renderer 模式最不费力的落地点。

**② 提示词只做粗控，精确排布交给图。**
`rule of thirds, subject on left third, negative space on right, foreground framing` 模型能抓个大概，但**像素级排布必须靠图**。文字定风格意图，图定实际坐标。

**③ 运动会破坏首帧构图——构图在视频里唯一的敌人。**
首帧构图完美，一旦相机/主体运动，构图会**漂移**（主体从三分点飘走、留白方向反了、前景框架滑出画）。所以：
- 静态镜/微动镜：首帧锁构图，稳。
- 大运动镜：用**首尾帧**同时锁「起始构图」和「结束构图」，让模型在两个合法构图间插值，避免中途崩坏。
> 接运镜档位——**运动越大，构图越需要首尾帧双锁**。

**④ 构图一致性 = 风格一致性。**
一场戏的构图习惯（都用三分、都留大量顶部空间、都有前景）应在 brief 里作为**全场构图基调**声明，每张首帧遵守。否则镜头间构图逻辑打架，观众觉得「不像一个人拍的」。类似焦段基调、轴线——跨镜头一致性约束。

**⑤ 竖屏/横屏构图不能共用一套图。**
画幅一变构图全变。同时出横竖两版，首帧必须**各画各的构图**，不能靠裁切——裁切会破坏三分点、留白和呼吸空间。

## 九、落地：构图进 spec 的字段结构

```yaml
composition (构图，2D 画面平面，下游维度):
  frame:
    aspect_ratio: 2.39:1 / 16:9 / 9:16 / 1:1   # 前置约束
  placement:                          # 主体放哪
    method: 三分/中心/对称/对角线/框架式/引导线/三角  # 可叠加
    subject_position: <主体在矩形的坐标区>
  balance:
    type: 对称 / 非对称
    negative_space: <留白方位与占比>
  room:                               # 呼吸空间，投影自轴线
    headroom: 适度
    looking_room: <看向侧留白>        # 方向 = 视线轴线
    lead_room: <运动前方留白>         # 方向 = 运动轴线
  lines:
    dominant_line: 水平/垂直/对角/曲线
    horizon: 高/中/低                 # 与机位高度联动
  focal_point: <视觉中心位置>          # 构图的最终目的
  eye_path: <视线动线设计>

  # —— 上游继承（不在本维度决策，来自别处）——
  inherits:
    depth_layers: <前中后景 ← blocking.md>   # 纵深分层归调度，构图只继承 2D 投影
    subject_size: <← 景别>
    perspective: <← 焦段>

  # —— 生成式执行 ——
  control_tier: 首帧图控（默认）/ 首尾帧（大运动镜）
  keyframe_ref: <MJ 首帧路径>          # 构图的实际载体
  scene_consistency: <全场构图基调>     # 跨镜一致性
```

**load-bearing 字段**：
- `focal_point` / `eye_path`——构图唯一不可省的东西。别的字段都是手段，这俩是目的。没想清「眼睛该往哪走」的构图，是纯装饰。
- `keyframe_ref`——构图的物理载体。在你的管线里，**这一格指向的 MJ 图才是构图真正被锁死的地方**，spec 里的文字只是它的意图注解。
- `inherits`——显式标注哪些不是构图自己决策的（分层来自调度、大小来自景别、透视来自焦段），是它作为**下游维度**的身份标识。

---

**一句话收束**：构图是从「相机在 3D 哪里」跨到「画面 2D 怎么看」的转换层，终极功能是**替观众设计眼睛的动线**。它在生成式里是**控制力最强、最干净的一维**——单帧属性，一张 MidJourney 首帧就能完整锁死，是 MJ→Seedance 管线里 renderer 模式最不费力的落地点。唯一的敌人是运动带来的构图漂移，解法是大运动镜上首尾帧双锁。

## 附：关联维度

- **调度（上游）**：前中后景**纵深分层归调度**，构图只继承其 2D 投影（见 `blocking.md` §三）；群戏焦点管理与调度耦合
- **轴线**：呼吸空间（looking/lead room）的方向 = 轴线在 2D 的投影
- **景别**：主体大小由景别决定，构图只排「这个大小的主体放哪」
- **焦段**：透视/景深由焦段决定，构图继承其结果
- **机位高度**：地平线在画框的高低与机位高度联动
- **运镜**：运动是构图漂移的唯一来源；大运动镜需首尾帧双锁构图
