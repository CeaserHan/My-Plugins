# 焦段 / 焦距 (Focal Length)

> **一句话核心**：焦段的本质不是「拉近拉远」（那是 zoom），而是**在景别已定的前提下，通过绑定摄距来雕刻空间的形状**——广角拉伸卷入、长焦压缩剥离。
> 它和景别正交却又经摄距联动，是整套体系里因果关系最绕、也最能体现「field-split 才能精确控制」的一维。

---

## 一、SSOT：焦距量的是「视角」，副产品是「透视压缩」

焦距（focal length，单位 mm）物理上决定**视角（field of view）**——镜头能「看进」多宽的世界。但画面上真正 load-bearing 的效果有两个，必须分开记：

| 焦距改变 | 直接效果 | 关键性质 |
|---|---|---|
| **视角宽窄** | 广角看得宽 / 长焦看得窄 | 这一层容易和「景别」混淆 |
| **透视压缩** | 广角拉伸纵深 / 长焦压扁纵深 | **焦段独占、不可替代的价值** |

### 最关键的第一性纠偏

很多人以为「是焦距造成了透视变化」，**错**。
**透视只由摄距（相机离主体多远）决定。** 焦距的真正作用是——为了在不同摄距下维持同样的景别，你被迫改变焦距，于是**焦距间接锁定了摄距，摄距才决定了透视**。

拆开这个因果链（本篇最重要的一段）：

```
你想要同一个景别（比如"脸充满画面"）
  ↓
广角 → 必须走很近才能填满 → 近摄距 → 强透视（鼻大耳小、纵深拉伸）
长焦 → 必须退很远才能填满 → 远摄距 → 弱透视（脸扁平、纵深压缩）
  ↓
所以"焦段的透视感" = 你为了维持景别被迫选择的摄距，带来的透视
```

**结论**：焦段和摄距是**一对被景别绑定的联动变量**。锁死「景别」后，「焦段」和「摄距」只剩一个自由度——选了焦段，摄距被反推确定，透视随之确定。
> 这就是为什么焦段必须是独立字段：**它是你在「景别已定」的前提下，唯一还能操控透视的旋钮。**

## 二、焦段全谱系（以 35mm 全画幅为基准）

| 焦段档 | mm（全幅） | 视角 | 透视性格 | 典型用途 |
|---|---|---|---|---|
| **超广角 / 鱼眼** | 8–14mm | 极宽，桶形畸变 | 极端拉伸，边缘扭曲 | 极端主观、迷幻、狭小空间、异化 |
| **广角** | 16–24mm | 很宽 | 强纵深、近大远小夸张 | 环境、气势、动作卷入、手持跟拍 |
| **准广角** | 28–35mm | 宽，畸变轻 | 自然偏纵深 | **纪实、「在场感」、街拍、多数运动镜** |
| **标准** | 40–55mm（50 为核） | ≈人眼 | 中性、无畸变 | 客观叙事、「看着像真的」、默认档 |
| **中长焦 / 人像** | 85–105mm | 窄 | 轻压缩、悦目 | **人像黄金焦段**、近景/特写、背景奶化 |
| **长焦** | 135–200mm | 很窄 | 强压缩、背景贴脸 | 特写、偷窥感、隔离主体、体育 |
| **超长焦** | 300mm+ | 极窄 | 极端压缩，空间「叠饼」 | 人群叠压、热浪感、极端隔离 |

> **画幅换算提醒**：上表是全画幅。M4/3、Super35、手机传感器有裁切系数，同「视角」需要的物理焦距不同。
> 但**生成式语境里不必纠结物理 mm**——模型理解的是「广角/标准/长焦」这种**视角+透视性格**的语义档，而非精确毫米数。所以 spec 里用**语义档 + 透视描述**，比裸 mm 更稳（见第七节）。

## 三、焦段独占的四个语义效果（剥离景别后）

最易被吃掉的部分。假设**景别恒定**（脸都填满画框），只换焦段，画面仍天差地别——这才是焦段不可替代的 load-bearing 价值：

**① 面部/物体的形变（透视畸变）**
广角贴脸 → 鼻子放大、脸颊后缩、「大头畸变」，攻击性/怪诞/主观感。
长焦远拍 → 五官比例自然压平，「上镜、好看」。
> 这就是**人像用 85mm+ 的真正原因**：不是为了拉近，是为了那个远摄距带来的悦目压缩。

**② 背景的远近感（纵深压缩）**
广角 → 背景被推得很远、很小，人物「孤立在广阔空间」。
长焦 → 背景被拉近、放大、「糊成一片贴在人身后」，人物**从环境里被抠出来**。
> 想让人物和环境剥离 → 长焦；想让人物嵌进环境 → 广角。

**③ 背景虚化程度（景深）**
焦段越长 → 景深越浅 → 背景越糊（配合大光圈）。长焦是「奶油背景」主力，广角天然景深深。
> 虚化 = 观众注意力的强制引导——长焦浅景深把眼睛钉在主体上。

**④ 空间的「密度感」**
长焦把纵深压扁，会让**一排纵向排列的物体/人叠压成密集的一片**（街道的车、人群、栏杆）。广角则把它们拉开、稀释。
> 想表达拥挤/压迫 → 长焦叠压；想表达空旷/疏离 → 广角拉伸。

> **一句话**：广角 = 拉伸空间、卷入环境、主观夸张；长焦 = 压缩空间、剥离环境、旁观隔离。
> 这条轴和景别**完全正交**——它管「空间的形状」，景别管「主体的大小」。

## 四、焦段 × 摄距四象限（把正交性钉死）

固定「脸充满画面」这个景别，只有两种实现，透视相反。但**放开景别**，焦段和摄距可自由组合出四种典型画面，各是一个成熟的电影语汇：

| | 近摄距 | 远摄距 |
|---|---|---|
| **广角** | 贴脸大头、强畸变、主观逼视（恐怖/迷幻/对峙） | 大远景、环境为主、人渺小、纵深深邃（史诗开场） |
| **长焦** | （罕见，需极长物理距离）超压缩特写、背景奶化贴脸 | 远距偷窥感、主体从人群剥离、压缩叠压（狙击视角/凝视） |

对角线是最有性格的两极：
- **广角 + 近**：世界扑面而来，攻击性、主观、不适。
- **长焦 + 远**：世界被抽离压平，旁观、疏离、宿命、「被观察」。

> 这张表和景别、机位高度都正交——**三者叠加才是完整的「视角气质」。**

## 五、焦段 vs Zoom vs Dolly：三个死结一次解开

三者永远被口语混淆，因为都能让主体变大。用框架切清：

| | 改变什么 | 相机动吗 | 透视变吗 | 归属字段 |
|---|---|---|---|---|
| **换焦段（定焦切换）** | 焦距（静态选择） | 不动 | **不变**（同摄距下） | 焦段字段（本篇） |
| **Zoom（变焦运动）** | 焦距随时间变 | 不动 | **不变**（裁切放大，扁平） | 运动字段（光学类） |
| **Dolly（移轨运动）** | 摄距随时间变 | **动** | **变**（真实纵深） | 运动字段（平移类） |

关键区分：
- **换焦段 vs zoom**：前者是开拍前**选定**的静态属性（这镜用 85mm）；后者是镜头**进行中**焦距在变（这镜从 24 变焦到 85）。一个是 spec 的「焦段字段取值」，一个是「运动字段里的 zoom 类型」。
- **zoom vs dolly**：都让主体变大，但 zoom 透视不变（扁）、dolly 透视变（有纵深）——这对死敌反向叠加 = **dolly zoom（眩晕镜）**。

> **眩晕镜的本质**（现在可精确表述）：摄距和焦距反向变化，让**景别恒定但透视剧变**——正是「焦段-摄距-景别」三角关系被撕开的极端演示。

## 六、焦段与已建维度的耦合关系

做 spec 要知道哪些是「联动」哪些是「正交」：

| 与哪个维度 | 关系 | 说明 |
|---|---|---|
| **景别** | **联动**（经由摄距） | 景别定了，焦段+摄距只剩一个自由度 |
| **机位高度** | 正交 | 任何焦段都能配任何高度 |
| **俯仰/朝向** | 正交 | 独立 |
| **相机运动** | 部分联动 | 运动改变摄距→若维持景别需变焦→引入 zoom；dolly zoom 是二者深度耦合 |
| **轴线/OTS** | 联动约束 | 正反打两镜**焦段必须相同**，否则两人不在「同一光学空间」 |

> **最实用的一条**：OTS 正反打里**焦段是必须镜像守恒的维度之一**。正打 85mm、反打 35mm，两人看起来像处在两个不同世界（一个压缩一个拉伸），空间统一感崩掉。

## 七、生成式视频语境：焦段怎么控、会怎么崩

焦段在生成式里的处境很特殊——**比运动好控，但比景别难控**。

### 模型对焦段的理解现状

- 模型**懂「广角/长焦」的语义**（视角宽窄 + 虚化 + 大致透视性格），响应尚可。
- 模型**不懂精确 mm 数**——写「shot on 85mm」它抓的是「人像感/浅景深/压缩」这个语义簇，不是真的 85 度视角几何。
- 模型**最容易崩的是「景别和焦段解耦」**：你要「广角的透视 + 特写的景别」（贴脸大头畸变），模型常给你普通特写，丢掉广角畸变；你要「长焦压缩的全景」，它给你普通全景。
  > **因为它把景别和焦段当一回事**——恰恰是它没做 field-split，需要你在提示词里强行掰开。

### 典型失效模式

| 失效 | 现象 | 原因 |
|---|---|---|
| 焦段被景别吃掉 | 要「广角贴脸畸变」，得到「普通特写」 | 模型默认焦段跟随景别 |
| 压缩感丢失 | 要「长焦压缩背景叠压」，背景仍舒展 | 透视是弱信号，易被忽略 |
| 虚化失控 | 要浅景深，全清楚 or 糊到主体 | 景深控制粒度差 |
| 畸变过度/不足 | 鱼眼要一点弯，给你极端桶形 | 量级词无分辨力 |

### 控制策略（映射档位/提示词框架）

**① 焦段用「透视效果」描述，不用 mm 数。**
别写 `50mm`，写模型真正能抓的语义簇。要长焦压缩特写：`telephoto compression, shallow depth of field, background compressed and blurred, flattened perspective`——把焦段拆成它的**四个独占效果**（视角/透视/景深/压缩）分别下词，比一个 mm 数稳得多。

**② 要「景别与焦段解耦」时，必须双重下词。**
要广角贴脸大头（广角透视 + 特写景别），提示词**同时**明确两件事：`extreme close-up`（景别）+ `wide-angle lens distortion, exaggerated perspective, enlarged features`（焦段透视）。只写一个，模型会用默认耦合把另一个抹掉。
> **这是焦段在生成式里最需要人工介入的场景**——你在对抗模型内建的「景别=焦段」耦合。

**③ 焦段是「全场一致性」字段，要在整场声明。**
同一场戏、同一光学风格（整场偏长焦压缩），应在 blocking brief 里**全场声明焦段基调**，每镜提示词继承。否则镜头间焦段乱跳，观众会觉得「这些镜头不像一部片子」。类似轴线——是跨镜头一致性约束，不是逐镜自由项。

**④ 焦段控制档位：**

| 焦段需求 | 崩坏风险 | 建议档位 |
|---|---|---|
| 标准焦段、常规景别 | 低 | 纯文字（透视语义词即可） |
| 明确长焦压缩/浅景深 | 中 | 文字 + 首帧（用一张已压缩/虚化的参考图定调） |
| 景别-焦段解耦（广角贴脸/长焦全景） | **高** | **首帧图控**——用参考图直接钉死反直觉透视，别指望文字 |
| 全场统一焦段基调 | 一致性风险 | 全场声明 + 每镜继承 + 首帧定调镜 |

**⑤ 焦段和 dolly zoom 的特殊处理。**
眩晕镜是焦段+摄距反向耦合，纯生成几乎不可控。策略同运动篇——**Blender previs 里把摄距轨迹 K 出来 + 明确变焦方向**作为视频参考喂进去，或拆成「先压缩→后拉伸」多段处理。

## 八、落地：焦段进 spec 的字段结构

```yaml
focal_length (焦段/焦距):
  semantic_tier: 超广角/广角/准广角/标准/中长焦/长焦/超长焦   # 语义档，非裸mm
  # —— 四个独占效果，供提示词展开 ——
  fov: 宽/中/窄                        # 视角
  perspective: 拉伸/中性/压缩           # 透视性格（焦段的灵魂）
  depth_of_field: 深/中/浅              # 景深/虚化
  spatial_density: 稀释/中性/叠压        # 纵深密度
  distortion: 无/轻/桶形                # 畸变

  # —— 联动/约束关系 ——
  bound_to_shot_size: true             # 与景别经摄距联动，非独立自由
  decouple_flag: false                 # 是否刻意做"景别-焦段解耦"（如广角贴脸）
  scene_consistency: <全场焦段基调>      # 跨镜一致性约束

  # —— 生成式执行 ——
  prompt_terms: [透视词, 景深词, 压缩词, 畸变词]  # 拆成效果下词，不写mm
  control_tier: 纯文字/首帧定调/首帧图控
```

> `perspective` 是这个结构的灵魂字段——**它是焦段唯一不可被景别或 zoom 替代的东西**。
> 视角能被裁切模拟、放大能被 zoom 模拟，但「广角的拉伸 / 长焦的压缩」这个空间形状，只有真实焦段（经摄距）能给。
> spec 若要精简，焦段这一维**最不能砍的就是 perspective**，其余四个效果都是它的派生描述。

> `decouple_flag` 是 field-split 哲学的直接兑现：默认焦段跟随景别（省事、模型友好）；一旦置真，就是声明「我要对抗默认耦合，手动指定一个反直觉的焦段-景别组合」——把「解耦」从隐性事故变成显式的、需图控加持的作者决策。

## 附：关联维度

- **景别**：经摄距与焦段联动——景别定了，焦段+摄距只剩一个自由度（核心耦合）
- **相机运动**：zoom = 焦距随时间变；dolly zoom = 运动与焦段深度耦合
- **机位高度 / 俯仰朝向**：与焦段正交
- **轴线 / OTS**：正反打两镜焦段必须镜像守恒（另属 OTS 文档）
- **视点归属**：主观镜常配广角（逼视）或特定畸变
