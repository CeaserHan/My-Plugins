# 调度 / 场面调度 (Blocking / Staging)

> **一句话核心**：调度是**唯一一个「镜头还没架就已经存在」的维度**。前面所有维度回答「相机怎么拍」，调度回答「相机要拍的那个世界，本身怎么组织」。
> 它坐在所有相机维度的**上游**——站位决定轴线，分层决定构图层次，走位决定运镜。

---

## 一、SSOT：调度量的是「3D 世界怎么被组织」

调度（blocking / mise-en-scène）描述——**相机介入之前，被拍摄的那个 3D 空间里，人和物摆在哪、朝哪、怎么动**。

### 范围边界（避免这个词膨胀）

广义 mise-en-scène 还含布景、灯光、服化、色彩、表演——但那些各有归属。**本维度只取「空间编排」这一核心**：

| 归本维度（空间调度） | 不归本维度（另有归属） |
|---|---|
| 人/物在 3D 空间的位置、间距、朝向 | 灯光（→ 光影维度） |
| 纵深分层（前中后景） | 色彩、服化（→ 美术维度） |
| 走位、移动路径、入出画 | 表演、微表情（→ 表演维度） |
| 景深配置（哪层清晰） | 布景、置景（→ 美术维度） |

精确名字是**空间调度 / 站位走位（staging & blocking）**，不是全套 mise-en-scène。

> **核心性质**：调度是导演对空间的编排，**独立于相机存在**。同一个调度（两人对坐、一人站一人跪），可用无数种景别/机位/焦段去拍——**调度是被拍的内容，相机维度是记录的方式**。

---

## 二、调度是上游：整套维度的依赖根节点

调度不是平级的第七维，是坐在所有相机维度上游的**根**：

```
调度（3D 世界怎么编排）  ← 先决策，先于分镜
  ├─ 纵深分层 ──────────→ 构图的层次（2D 显影）
  ├─ 人物站位 ──────────→ 轴线（关系线由站位决定）
  │                    └─→ 构图呼吸空间（looking/lead room）
  ├─ 走位路径 ──────────→ 运镜（跟拍、入出画）
  └─ 景深配置 ←──耦合──→ 焦段
```

**读法**：轴线在哪、构图往哪留白、镜头怎么跟——**根都在调度**。是「人怎么站」决定了轴线，不是反过来。
> 这就是为什么实际管线是 **script-blocking-analysis 先于 storyboard**——blocking 就是那个必须先锁死的上游层，分镜是在已定调度上的相机选择。

一句话定位：**调度定「世界怎么摆」，其余六维定「怎么拍这个摆好的世界」。**

# ▊ 基础层：调度的六个部件

## 三、纵深分层（前中后景）

因在 3D（东西摆在哪个纵深带），果在 2D（投影成构图层次）。作为**调度决策**：

| 层 | 空间位置 | 调度职责 | 语义/价值 |
|---|---|---|---|
| **前景（FG）** | 离镜头最近 | 放遮挡物、框架物、虚焦元素 | 加纵深、加层次、「偷窥/在场」感、把观众「隔在外面」 |
| **中景层（MG）** | 主体所在带 | 放主要表演主体 | 戏剧焦点，注意力落点 |
| **背景（BG）** | 最远 | 放环境信息、次要动作、氛围 | 交代空间、烘托、或虚化剥离 |

**分层的调度要点**：
- **前景层是最被低估的调度工具**。镜头前主动放个东西（栏杆、肩、植物、门框），画面立刻有纵深和电影感。画面「平」，往往是**只调度了中景，忘了前景层**。
- **背景次要动作（background action）**是高阶手法——背景有人走动，空间就「活」了。但要控其视觉重量，别抢中景焦点。
- **三层纵深间距本身是调度决策**：挤在一起（浅纵深）vs 拉得很开（深纵深），配合焦段，决定空间张力。

## 四、人物站位（Static Blocking）——空间关系即戏剧关系

用空间几何表达人物关系（proxemics，人际距离学）：

| 空间参数 | 调度决策 | 表达的戏剧关系 |
|---|---|---|
| **距离（间距）** | 两人靠多近 | 亲密 ↔ 疏远 |
| **高低（谁站谁坐）** | 一站一坐、一高台一低处 | 权力落差 |
| **前后（谁离镜头近）** | 谁在前谁在后 | 注意力层级、主从 |
| **朝向（面/背/侧对）** | 身体转向 | 面对=交流/对峙，背对=拒绝/隔阂，侧对=并行/暧昧 |
| **围合方式** | 多人如何成组 | 阵营、排斥、层级 |

> **关键**：站位一旦定死，**轴线就定死了**（关系轴线 = 两人连线）。摆人那一刻，就决定了后面所有镜头的轴线约束——这是轴线的「因」在调度。

**多人靠「几何构成」**：三人别站一排（呆板、轴线混乱），站成**三角形**（有前后纵深、有主次、轴线清晰）。群戏靠预先画俯视 blocking 图——这张图同时是**轴线 SSOT + 分层依据**。

---

## 五、景深配置（Depth Staging）——哪层清晰=给哪层分配权重

调度定三层空间关系，景深定这三层里哪些「可见、清晰、承重」。与焦段耦合，但决策属调度：

| 配置 | 做法 | 调度语义 |
|---|---|---|
| **深焦（Deep focus）** | 前中后全清晰 | 前中后景**同时承载信息**，观众自选看哪层；民主、写实、信息密集 |
| **浅焦（Shallow focus）** | 只主体清晰，前后虚化 | **强制注意力**在一层，其余降为氛围；主观、聚焦、情绪 |
| **焦点转移（Rack focus）** | 清晰层在镜头内切换 | 用清晰度移动**引导注意力从一层跳到另一层**，动态手段 |

> **本质**：景深配置=给哪一层分配视觉权重。深焦=权重均摊多层，浅焦=权重压在一层。比构图更底层（构图排 2D 位置，景深决定哪层进入注意力）。

---

## 六、走位（Dynamic Blocking）——空间编排随时间变

**① 移动路径**：轨迹本身有语义——朝镜头走（逼近/揭示）、远离（离去/抽离）、横穿（过渡/不安）、绕行（试探/包围）。

**② 入画 / 出画**：从画框哪个边进出，直接影响——
- **轴线**：左进 vs 右进，建立不同运动方向
- **构图呼吸空间**：出画方向要预留 lead room
- **组接**：上镜出画一侧接下镜进画对应侧（方向匹配剪辑）

**③ 走位与运镜的耦合——调度的最高阶命题**：

| 模式 | 谁在动 | 效果 |
|---|---|---|
| **人动镜不动** | 演员走位，相机固定 | 舞台感、客观、让空间说话 |
| **镜动人不动** | 相机运镜，演员静止 | 相机主动「探索」，主观引导 |
| **双动（跟拍/调度长镜）** | 人和镜同时动、相互编排 | 最复杂、最沉浸；长镜头调度的核心 |

> **双动是场面调度的珠峰**：人走位和相机运镜像舞蹈一样互相咬合，一镜之内不断重构景别、机位、构图。长镜头难，就难在它是**调度和运镜的实时联合求解**。

# ▊ 进阶层：调度的 craft（用空间写戏）

> 门道不在「有哪些类型」，而在**空间怎么承载意义、怎么随时间控制眼睛**。这一层把 blocking 从「让演员站到标记点」升级成「用空间写戏」。

## 七、近体学被武器化：重点是「距离的变化」

人际距离有心理分区：亲密区（<45cm）· 个人区（45cm–1.2m）· 社交区（1.2–3.6m）· 公共区（>3.6m）。观众身体本能就懂。

高手不是「摆在社交距离」，而是**让人跨越分区**：
- A 从社交距离**逼进**B 的亲密区 → 观众身体紧张 = **侵犯/威胁/求爱**，一个动作胜过台词。
- 两人本在亲密距离，一方**后撤** → 关系刚刚破裂，无需台词。

> **静态站位定「此刻关系是什么」，走位（距离变化）定「关系正在发生什么」。**
> 一场戏的调度骨架，本质是一条**距离曲线**——何时逼近、何时拉开，对应戏剧的进逼与退让。摆好起始距离和结束距离，中间走位就是这场戏的**情绪导数**。

---

## 八、动机与 business：没有理由的走位=演员在「踩点」

区分业余和专业调度**最硬的一条**。每次移动必须有**动机**——一个「想要」，或挂靠一个 **business（手上的活）**。

**business** = 人物手上正做的具体动作（泡咖啡、擦枪、整理文件、点烟），作用三层全 load-bearing：
1. **给走位借口**——不会无缘无故走到窗边，但「去倒杯水」顺理成章，走位被合法化。
2. **泄露内心**——擦枪的力度、点烟的手抖，是潜台词的物理出口。
3. **给对话节奏**——台词停顿挂在动作上（说完狠话慢慢放下杯子），节奏有肉体感。

> 没有动机的走位会被潜意识识破——画面有种说不清的「假」，那就是「演员在踩标记点」而非「人物在空间里生活」。

**→ 动画背景直接映射**：这就是动画里 **pose 要有 intent、动作要有 motivation**。真人调度的动机原则，和画关键帧时「这个 pose 为什么存在」是同一判断。你已有这套肌肉记忆，只是从 2D 平面挪到 3D 空间。

## 九、权力几何：谁动、谁不动——静止即权力

调度里最反直觉、也最深的一条：**空间里保持静止的人，往往最有权力。**

- **不动的人掌控空间**——别人围着 ta 转、走向 ta，ta 是引力中心。老板坐着不动，下属站着说话。
- **移动的人在消耗/暴露**——踱步=焦虑，趋近=有所求，绕行=试探。谁在动，谁在**让渡控制权**。
- **权力反转写法**：强弱易位，就让原本静止的人开始移动（失控），移动的人停下站定（夺权）。「谁先停下」的瞬间=权力反转的视觉锚点。

配套空间权力工具：
- **高度**：高台、楼梯、站vs坐——垂直落差=支配落差（**演员的**高度，非相机的）。
- **领地与门槛**：跨过门槛（threshold）是强动作——进入别人领地、或被逐出。门框、门口是天然张力点。
- **背对**：背对一人继续做事 = 最强的轻蔑/掌控。

> 这一套是**用空间几何直接写权力**，比台词底层。观众不需「读懂」，身体直接感受到。

## 十、开放/封闭 与 强弱位置（舞台遗产 + 为镜头作弊）

**开放 vs 封闭身位（open / closed）**：
- 开放=身体转向镜头；封闭=转离。
- 现实里对话互相侧对，但那样两张脸都「封闭」、读不到表情。演员会 **cheat out（向镜头作弊）**——略转向镜头，哪怕物理上不完全自然。
- **对你是解放性洞察**：实拍要在「自然」和「可读」之间妥协；**动画/生成式没有这约束**——可纯为「读得清」来 block，不必迁就自然。**你的调度自由度比实拍导演更大。**

**强弱位置**：

| 位置 | 强度 | 说明 |
|---|---|---|
| 正面朝镜头 | 最强 | 完全暴露、直接、支配 |
| 四分之三 | 强、自然 | 常用主位 |
| 正侧（profile） | 中/弱 | 客观、旁观 |
| 背对 | 最弱—或神秘 | 拒绝暴露，配合语境=强控制 |
| downstage（离镜头近） | 强 | 前景占位、注意力优先 |
| upstage（离镜头远） | 弱 | 被「压」在后面 |

> **upstaging（抢上位）**：一演员往后站，逼对手转身背对观众跟 ta 说话，偷走注意力。调度要**主动分配谁占强位**——给当下戏剧焦点的人。

## 十一、Blocking Beat：在「转折」上换调度

**调度的时间结构，最易被忽略的门道。**

一场戏拆成若干 **beat（节拍）**——每个 beat 是一个「想要」驱动的动作单元，beat 之间是**转折**（tactic 改变、力量易位、新信息进入）。

**铁律：调度在 beat 的转折点上改变。**
- 关键台词上**站起来**——若卡在转折点，放大台词；卡错地方，成无意义的动。
- **move on the line vs move on the turn**：台词中间移动分散注意力；转折点移动**标点**那个转折。老手把每次走位精确卡在潜台词转向的那一刻。
- 反过来，**没有转折的对话就不该有走位**——静止让观众专注台词交锋。每句话都晃=新手病，稀释而非强调。

> **调度的时间设计 = 把空间变化对齐到戏剧关节。** 站位对应「关系状态」，走位对应「关系转折」，静止对应「专注交锋」。
> 一场戏的 blocking，读起来应是这场戏潜台词结构的**空间转录**。
> **→ 直接接 script-blocking-analysis**：拆 beat → 找转折 → 在转折点安排调度变化。

## 十二、动态编排的大师层：不切镜就换焦点

调度和运镜**联合求解**的顶峰，长镜头调度的核心机密。

**核心能力：一个镜头内，通过调度重构画面，实现本需「剪辑」才能完成的事。**

| 机制 | 做法 | 承担的剪辑职能 |
|---|---|---|
| **Reframe without cutting** | A 起身走向窗，镜跟摇过去，双人镜无缝变 A 单人镜 | 换景别/换焦点 |
| **The hand-off（焦点交接）** | 镜跟 A 穿房间到 B 身边停下，重构图到 B | 一个运动镜串两个焦点 |
| **Reveal blocking（揭示性调度）** | 前景 A 挡住 B，A 移开露出 B | 控制信息出现的时序 |
| **三角走位 + counter（对位补偿）** | A 移动，B 反向补位维持平衡 | 三人以上保持画面不乱 |

> **共同本质**：用空间调度承担「剪辑」的职能——转焦点、给信息、换景别，全在一镜内靠人和镜的编排完成。这引出下一节对你战略级的美学分叉。

---

## 十三、纵深调度 vs 剪辑：一个美学分叉，生成式偏爱前者

**整个调度维度里对战略层最重要的一点。**

电影史两条对立的意义建构路线：
- **蒙太奇路线（Eisenstein）**：意义**在镜头之间**产生。多切快切，靠组接生成含义。碎片化。
- **纵深调度路线（Bazin 推崇的 Welles/Wyler/Renoir）**：意义**在单镜内部**产生。少切，前中后景全调度进一个深焦画面，观众自选看哪层，时空连续不被剪辑打断。

深焦纵深调度的威力：一画面里前景 A 打电话、中景 B 偷听、背景 C 推门进来——**三个戏剧层同时进行，眼睛自己游走**。全靠调度，不靠一次剪辑。这是调度的最高形态。

**为什么对你的生成式管线是战略级**：

生成式视频**天然厌恶剪辑、偏爱长单镜**——每个 clip 独立生成，剪辑点是一致性崩坏的高发区（切一次就要重新对齐轴线、角色、光线）。

> **蒙太奇路线在生成式里是逆水行舟（多切=多崩坏点），纵深调度路线才是顺水推舟（把戏放进单个可控深焦画面，用调度而非剪辑承载信息）。**

**分镜策略应主动向纵深调度倾斜**：能用「前中后景分层 + 景深 + 一次 reframe」在单镜里讲完的，别拆成三镜切。既**降低崩坏率**，又**恰是电影语言的高级形态**——技术约束与美学高度罕见地对齐。
> renderer 模式在这里升级成**美学主张**：用调度深度替代剪辑频度。

## 十四、群戏焦点管理：在人堆里指挥眼睛

多人同框，「观众先看谁」全靠空间工具：

- **层级隔离**：焦点人物给独立纵深层/空隙，其余挤另一层——用分层把焦点拎出来。
- **汇聚线由人构成**：配角身体朝向、视线**都指向**焦点，人群变引导线。
- **孤立**：焦点周围留一圈空隙，负空间标出 ta。
- **反差运动**：全静止焦点动，或全动焦点定。运动反差=注意力磁铁。
- **高度**：焦点略高（站起、台阶），从人海冒头。

> 群戏靠**预先俯视 blocking 图**逐人锁朝向位置——同时是轴线 SSOT、构图分层依据、焦点管理方案。

## 十五、桥：调度 = 动画「Staging」原则的 3D 版

**你其实已精通调度，只是叫它别的名字。**

迪士尼十二原则里的 **Staging（布局/演出）**：*把一个想法呈现得毫无歧义地清晰，引导注意力到该看的地方，一镜一主意。* 这和电影调度是**同一件事**：

| 动画原则（你已有） | 调度对应（同一件事） |
|---|---|
| **Staging：一次一个清晰主意** | 一场戏一个戏剧焦点，别让多动作打架 |
| **Silhouette（剪影可读性）** | 站位/身位在轮廓上就读得清（开放身位、别遮挡关键动作） |
| **Line of action（动作线）** | 单体 pose 的清晰走向 = 单人站位的身体朝向语义 |
| **Anticipation / staging the pose** | 转折点上「摆好 pose」再发力 = beat 转折上定住调度 |
| **Appeal / readability 优先于 naturalism** | 为「读得清」作弊（cheat out）优先于物理自然 |

> **最深的一条迁移**：动画师天生**不受物理自然约束**——摆 pose 为 read 和 appeal，不为「真人会怎么站」。这是实拍导演最羡慕、最难做到的调度自由。
> **做生成式调度时，带着动画师这个特权**：纯为画面清晰度、戏剧重量、剪影可读性来 block，扔掉「自然主义」的枷锁。这是你相对实拍出身者在调度上的**结构性优势**——别浪费它。

# ▊ 生成式落地

## 十六、调度是「分裂人格」的一维

调度在 AI 里**一半最好控、一半最难控**，取决于静态还是动态：

| | 静态调度（站位/分层/景深） | 动态调度（走位/双动） |
|---|---|---|
| 性质 | 单帧的空间摆位 | 跨帧的空间变化 |
| 可控性 | **首帧图控可锁死**（同构图） | **继承运动的全部难点 ×多人一致性** |
| 对应档位 | 首帧 | 首尾帧 + previs |

**静态调度：最好控的那一半**
站位、分层、景深都是**单帧属性**，完全活在首帧里。**Blender previs + MJ 首帧就是调度控制器**：
- **Blender previs 锁站位和分层**：clay 模型摆好前中后景、多人站位、相机相对关系，playblast=一张调度已定的空间参考。（这是 previs 在**调度维度**的价值，区别于它在运动维度锁轨迹。）
- **MJ 首帧锁景深和分层显影**：前景虚焦、主体清晰、背景氛围排好。
- Seedance 继承首帧 → 调度被继承，模型不需「理解」你的站位意图。

**动态调度：最难控的那一半**
走位继承运动的所有失效模式，且**更糟**——常是**多人同时动**：
- **多人走位 = 多个一致性负担同时漂移**。两人边走边说，模型要同时守两个 ID + 相对站位 + 轴线，崩坏率极高。
- **入出画不可控**：模型不知让谁从哪边出，方向匹配靠首尾帧钉。
- **双动几乎不可能一镜生成**：人走位 + 镜运动的联合编排，远超一次采样能力。

### 对策（映射 blocking-analysis 层和控制档位）

**① 调度 SSOT = 俯视 blocking 图 + 距离曲线 + beat 对齐表**（深化版）。
静态俯视图只锁「此刻站哪」；完整 brief 还要有**这场戏距离怎么随 beat 变化**（谁在哪个转折逼近/退开）。这决定走位镜在哪些点切分。这张图同时喂给轴线（关系线）、构图（呼吸空间方向）、运镜（走位路径）。

**② 主动选纵深调度、少剪辑——生成式的顺势而为。**
能用分层+景深+单次 reframe 在一镜讲完的，别拆多镜。分镜决策加一条显式偏向：「**这段能不能用一个深焦调度镜替代三个正反打切镜？**」技术降崩坏，美学是高级形态。

**③ 静态用首帧/previs 锁，走位做减法。** 能拆成静态段就别让人走位；必须走位的，用首尾帧锁住「走位起点站位」和「终点站位」，模型只插值中间。

**④ 多人同框走位标为最高风险。** 崩坏率天花板。能拆单人镜就拆；必须同框的，previs + 双角色 ref + 首尾帧多重锁；双动镜考虑拆成多个单动镜再剪。

**⑤ 分层用景深主动降负担。** 前景虚焦、背景虚焦不只是美学——**虚化的层模型不用精细渲染，崩坏风险直接降低**。主动把非焦点层推进浅景深，既是调度语义，又是给模型减负。

**⑥ 动态调度值得上重型图控。** 不切镜的 reframe 对生成式是双刃：省了剪辑崩坏点，但要求一镜内维持多变构图和一致性。策略——**Blender previs 把「人的走位路径 + 相机的 reframe 轨迹」作为一套联合编排 K 出来**，playblast 成参考。这是 previs 在调度维度最高阶的用法：**同时锁人的走位和镜的运动这一对舞蹈**。

**⑦ 带动画师特权 block。** 为 read 作弊、为剪影摆位、一镜一主意——把已有的 staging 直觉当成默认工作方式。

## 十七、落地：调度进 spec 的字段结构

```yaml
blocking (调度，3D 空间编排，上游 SSOT):
  scope: 空间调度（站位/走位/分层/景深）  # 不含灯光/服化/表演
  depth_layers:                        # 纵深分层（从构图迁入）
    foreground: <前景放什么，虚实>
    midground: <主体>
    background: <环境/次要动作>
  staging:                             # 静态站位
    positions: {A: ..., B: ...}        # 3D 相对位置
    proxemics: 距离/高低/前后/朝向       # 空间关系=戏剧关系
    group_geometry: 三角/围合/排布
    open_closed: <各角色开放/封闭身位>   # 强弱位置
  depth_config:
    focus_type: 深焦/浅焦/焦点转移
    weight_layer: <哪层承载注意力>
  movement:                            # 走位（动态）
    paths: <各角色移动轨迹>
    entrance_exit: <入出画的边>
    cam_actor_coupling: 人动/镜动/双动
  # —— craft 层（时间与语义）——
  distance_curve: <这场戏的距离随 beat 变化>   # 情绪导数
  beat_alignment: <每次调度变化对齐的转折点>    # 调度=潜台词空间转录
  business: <各角色手上的活，走位的动机来源>
  power_geometry: <谁静谁动，静止=权力>
  staging_bias: 纵深调度优先 / 剪辑优先        # 生成式默认前者
  # —— 下游依赖（本维度输出给谁）——
  feeds:
    axis: <站位→轴线>
    composition: <分层→构图层次；朝向→呼吸空间>
    movement: <走位→运镜跟拍/入出画>
  # —— 生成式执行 ——
  scene_blocking_map: <全场俯视 blocking 图路径>   # 核心 SSOT 产物
  control_tier: 首帧/previs（静态） | 首尾帧+previs（走位）
```

**load-bearing 字段**：
- `scene_blocking_map`——调度的物理载体，也是轴线/构图/运镜的共同上游输入。**这张俯视图是整场戏空间的真相源。**
- `feeds`——显式声明输出给哪些下游维度，是它作为「根节点」的身份标识，也是 KB 挂接其他文档的接口。
- `distance_curve` + `beat_alignment`——把调度从「静态摆位」升级为「随戏剧转折运动的空间结构」，是 craft 层的核心，也是防止调度沦为「摆好看」的动机锚。

---

**一句话收束**：调度是「相机介入之前，世界怎么编排」的维度，坐在所有相机维度上游——站位决定轴线，分层决定构图层次，走位决定运镜。它的 craft 是**用空间几何写权力、用距离曲线写情绪、用 beat 对齐写潜台词、用纵深调度替代剪辑**。在生成式里它人格分裂：静态站位/分层最好控（一张 previs/首帧锁死），动态走位最难控（继承运动难点 ×多人一致性）。你的 script-blocking-analysis 层，本质就是这个上游维度的工程化——而你的动画 staging 直觉，是别人没有的起手优势。

## 附：关联维度（调度是上游根节点，输出给以下下游）

- **轴线**：站位（关系连线）→ 轴线的「因」。轴线文档是它作为组接约束的展开
- **构图**：纵深分层 → 构图 2D 层次；人物朝向 → 构图呼吸空间（looking/lead room）
- **运镜**：走位路径 → 跟拍相位、入出画；双动 → 调度与运镜联合求解
- **焦段**：景深配置 ←→ 焦段（哪层清晰的实现手段）
- **机位高度**：注意区分——调度里是**演员的**高度（权力落差），机位维度是**相机的**高度
