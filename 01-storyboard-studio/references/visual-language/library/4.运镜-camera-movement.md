# 运镜 / 相机运动 (Camera Movement)

> **一句话核心**：运镜是**唯一一个「上游（Blender）能精确作者化、下游（Seedance）却极难自由采样」的维度**。
> 所以对生成式管线，运动不是「写好提示词」的问题，而是「**把 previs 轨迹作为 SSOT，让模型退化成插值器/渲染器**」的问题——运动维度是 renderer 模式最锋利、也最不得不用的战场。

---

## 一、SSOT：运动 = 姿态对时间的导数

静态机位 = 6DOF 姿态（XYZ 位置 + Pan/Tilt/Roll 朝向）。
**相机运动的定义就是这套姿态值随时间变化。** 没有任何一种运动逃得出这个框架：

| 变化的轴 | 就是这个运动 | 中文名 |
|---|---|---|
| ΔX（左右平移） | Truck / Track | 横移 |
| ΔY（上下平移） | Pedestal / Boom | 升降 |
| ΔZ（前后平移） | Dolly | 推 / 拉（移轨） |
| ΔPan（水平转） | Pan | 摇（水平摇） |
| ΔTilt（俯仰转） | Tilt | 摇（垂直摇 / 甩） |
| ΔRoll（横滚转） | Roll | 横滚 |
| Δ焦距（**非姿态**） | Zoom | 变焦 |

**最关键的一刀**：前六行是**相机在空间里真的动了**（姿态变），第七行 zoom **相机纹丝不动，只是焦段在变**。二者都能让主体变大/变小，所以口语永远混为一谈，但物理上是两回事——运动体系里第一个必须 field-split 的点（详见第四节）。

### 三条正交描述轴（整个运动 spec 的骨架）

| 轴 | 回答 | 例子 |
|---|---|---|
| **几何类型** | 哪条轴在动 | ΔZ 推进、ΔPan 摇、环绕 |
| **质感 / rig** | 怎么动（正交于几何） | 同一个推进：轨道推=丝滑，手持推=摇晃 |
| **动机** | 为什么动 | 主体驱动 / 揭示驱动 / 情绪驱动 |

> 任何一个镜头的运动 = 在这三轴上各取一个值。**三轴独立**，不可合并。

---

## 二、旋转类运动（相机位置不动，只转朝向）

相机像三脚架上的头，原地转。**特征：视差不变**——相机没位移，前后景相对关系不变，只是「扫过」空间。

| 运动 | 轴 | 中文 | 语义 |
|---|---|---|---|
| **Pan** | Pan（绕 Y 转） | 水平摇 | 扫描空间、连接两点、跟随横向运动、POV 环视搜寻 |
| **Tilt** | Tilt（绕 X 转） | 垂直摇 | 上摇=仰视揭示高大/威严；下摇=揭示脚下/审视 |
| **Whip pan** | Pan 极快 | 甩摇 | 快速转场、暴力衔接两个空间、动感 |
| **Roll** | Roll（绕 Z 转） | 横滚运动 | 罕见作为运动，多用于转场/失衡渐变 |

> **上摇 tilt-up** 是经典「揭示尺度」手法：从人脚摇到楼顶，观众的敬畏感是**被相机的仰视轨迹一点点喂出来的**，比直接给一个大仰角静态镜更有过程感。

---

## 三、平移类运动（相机真的在空间里走）

相机整体位移。**特征：视差改变**——前景相对背景滑动，产生真实三维纵深。这也是它比旋转类「贵」、比 zoom「真」的原因。

| 运动 | 轴 | 中文 | 语义 |
|---|---|---|---|
| **Dolly in（推）** | +Z 逼近 | 推轨 | **收拢注意力、逼入内心、张力/顿悟渐强**。慢推=经典「意识到了什么」 |
| **Dolly out（拉）** | −Z 后退 | 拉轨 | **揭示环境、抽离、孤独、释放/结束**。人物在扩大空间里变小 |
| **Truck / Track（横移）** | ΔX 侧移 | 横移轨 | 沿平面揭示、平行跟随、长卷式群像、扫过一排人/物 |
| **Pedestal up（升）** | +Y 上升 | 升 | 升起、揭示纵向空间、俯瞰前的抬升 |
| **Pedestal down（降）** | −Y 下降 | 降 | 沉入、落地、贴近 |
| **Crane / Jib（升降臂）** | ΔY + 常带 ΔZ/ΔTilt | 升降臂 | 复合大幅度运动，最「华丽」，常用于开场揭示或结尾抽离 |

> **推 vs 拉是操控情绪节奏的主旋钮**：推=往里走，观众被拽进主观世界；拉=往外走，观众被推回客观旁观位。
> 一场戏的推拉曲线本身就是情绪结构（先推后拉 = 进入再抽离 = 一个完整的情感呼吸）。

> ⚠️ **术语坑**：Dolly / Track / Truck 在不同体系里指代会串。最稳的自保办法是**别用名词，用轴**——「沿 +Z 逼近」永远无歧义。spec 里用轴+方向，不用民间名词。

---

## 四、光学类：Zoom，以及为什么它和推拉是死敌

Zoom 不动相机，只改焦距，把画面**裁切放大**。它和 dolly 都让主体变大，但机制相反：

| | Dolly in（推，物理逼近） | Zoom in（变焦，光学放大） |
|---|---|---|
| 相机 | 真的往前走 | 原地不动 |
| 视差 | **变**（前景相对背景滑动，有纵深） | **不变**（像裁切一张照片，扁平） |
| 透视 | 空间感真实 | 空间被「压平」，有廉价/监控感 |
| 观感 | 电影感、沉浸 | 生硬、抓拍感、刻意 |

> **「能推轨绝不 zoom」**——zoom 的扁平感会暴露「这是镜头在变，不是我在走近」。
> 但 zoom 也非原罪：突然 zoom 有强抓取感（恐怖片、纪录片式抢拍），是特定风格工具。

### Dolly Zoom（滑动变焦 / 眩晕镜 / Vertigo shot）

把这对死敌**反向叠加**：一边推轨逼近、一边反向 zoom out（或反之），让**主体大小不变、但背景透视疯狂扭曲**。
语义：**天旋地转、脚下世界在塌、心理断裂、恐惧/眩晕。**
> 它是「运动可由多轴反向协同构造出新语义」的最漂亮例证——单看每轴都在动，合起来主体却像被钉住，只有世界在变形。

## 五、复合运动 = 多轴协同（名词的真相）

所有「高级运镜」的名字，拆开都只是几条基础轴的**协同**：

| 复合运动 | 中文 | 拆解 | 语义 |
|---|---|---|---|
| **Arc / Orbit** | 环绕 / 弧移 | ΔX/ΔZ 走圆 + ΔPan 持续对准主体 | 把静止主体三维化、加剧戏剧性、亲密或眩晕 |
| **Crane shot** | 升降臂镜 | ΔY + ΔZ + ΔTilt 协同 | 大开大合的揭示/抽离，「上帝抽身」结尾 |
| **Dolly zoom** | 眩晕镜 | ΔZ + Δ焦距 反向抵消 | 世界崩塌、心理断裂 |
| **Follow / Tracking** | 跟拍 | 平移速度匹配主体速度 | 与人物同行、沉浸、卷入 |
| **Reveal** | 揭示镜 | 任意运动 + 前景遮挡的解除 | 从遮挡后「掏出」新信息，制造惊喜/悬念 |

> **环绕 orbit** 是理解「协同」的最好例子：它不是单一轴，是**平移画圆 + 水平摇实时补偿**两轴联动，目的是让主体始终居中、背景整片旋转。
> 任何自动化/生成式系统要复现它，都得同时算准两条轴的耦合——这也预告了它在模型里为什么最容易崩（第八节）。

## 六、质感 / rig 轴（正交维度：同样的几何，不同的手感）

前面全是「往哪动」。这一轴管「动得多稳/多晃」，**和几何完全独立**——任何几何运动都能用任何 rig 实现，语义天差地别：

| Rig / 质感 | 中文 | 手感 | 语义 |
|---|---|---|---|
| **Locked-off** | 固定 | 绝对静止 | 客观、冷峻、舞台感、observational |
| **Fluid head** | 云台摇 | 平滑摇/俯 | 规整、传统叙事 |
| **Dolly / Track** | 轨道 | 机械丝滑 | 高级、精确、「设计过的」 |
| **Steadicam** | 斯坦尼康 | 漂浮式跟随 | 梦境感、沉浸、穿行空间 |
| **Gimbal** | 稳定器 | 平滑漂浮 | 现代感、流畅、无重量感 |
| **Handheld** | 手持 | 晃动、呼吸感 | 即时、混乱、真实、主观、紧迫 |
| **Drone / Aerial** | 航拍 | 大范围平滑飞行 | 地理尺度、抽离、宏观 |
| **Snorricam** | 体固定 | 相机绑在演员身上 | 主体钉死、世界疯转，眩晕/精神异常 |

> **手持 vs 斯坦尼康**是这一轴的语义两极：同一个「跟人穿过走廊」的几何轨迹，手持=纪录片式紧张卷入，斯坦尼康=库布里克式诡异梦游。
> **几何一样，情绪相反**——所以质感必须是独立字段，绝不能和运动类型合并。

## 七、跟拍关系（相机相对移动主体的位置）

当主体在动，「跟」细分成几种相位，各有语义：

| 跟法 | 中文 | 相机位置 | 语义 |
|---|---|---|---|
| **Following** | 后置跟 | 主体后方，跟着走 | 观众「跟随」人物、未知前方、悬念 |
| **Leading** | 前置跟 | 主体前方，倒着退 | 观众「迎面」看人物、读表情、被人物「推着走」 |
| **Side / Parallel** | 侧跟 | 与主体平行侧移 | 客观并行、展示行进姿态、公路片感 |

> **前置跟拍**（相机在人物前方后退）是揭示表情的利器——人物向前走、脸始终对着你，能读到 ta 边走边变化的情绪；后置跟则把观众绑进「和 ta 一起面对未知」的处境。
> 三种都建立在**运动轴线**之上，跟错边就越轴（见轴线文档）。

## 八、生成式视频语境：运动为什么最难，怎么控

**运动是生成式视频里失控率最高的维度**，原因是结构性的：

| 静态画面 | 相机运动 |
|---|---|
| 模型只需生成一个稳定构图 | 模型要生成**几十帧内几何连续变化**的序列 |
| 一致性只需守住单帧 | 运动越大 → 帧间几何漂移越大 → **人物脸/结构越易 morph** |
| 提示词能锁构图 | 提示词几乎锁不住「运动的速度/幅度/曲线」 |

### 典型失效模式

| 失效 | 现象 |
|---|---|
| **幅度失控** | 写「slow push in」，要么纹丝不动，要么猛冲——量级词几乎无分辨力 |
| **环绕崩坏** | orbit 双轴耦合，主体越转越变形，背景撕裂、人脸「换人」 |
| **运动 × 一致性打架** | 镜头动得越狠，角色 ID 漂移越严重，快速运镜里五官中途重组 |
| **Zoom / dolly 坍缩** | 模型分不清「推进」和「变焦」，要纵深推轨给你扁平放大 |
| **复合运动解析失败** | 「crane up while dollying in」多轴指令，基本只执行一条或全糊 |

### 控制策略（正是 Blender previs 管线的核心价值）

**① 运动别靠提示词，靠轨迹图控。**
文字对运动的控制力是所有维度里最弱的。**Blender previs 的最大意义就在运动这一维**：在 Blender 里把相机 XYZ + 朝向的**完整时间轨迹**精确 K 出来，clay/flat-shaded 播放成一段视频，作为 Seedance 视频参考（omni-reference）喂进去——模型不是在「理解」你的运镜文字，而是在**照抄一条已存在的运动轨迹**。
> 这把「运动」从「祈祷模型采样对」变成「上游作者化、下游执行」= renderer 模式在运动维度的落地。

**② 首尾帧锁两端，模型只负责中间插值。**
运动 = 起始姿态 → 结束姿态的过渡。给**首帧和尾帧**分别钉死「运动开始/结束时的构图」，模型采样空间被压到只剩「怎么从 A 平滑走到 B」。幅度和终点被锁死，失控率骤降。
> **运动幅度越大、越该上首尾帧。**

**③ 控制档位按运动复杂度分级：**

| 运动类型 | 建议档位 | 理由 |
|---|---|---|
| 固定 / 极轻微推拉 | 纯文字 | 几何几乎不变，模型稳得住 |
| 单轴匀速（慢推、横移、pan） | 首帧 or 首尾帧 | 锁住构图起点/终点即可 |
| 环绕 / crane / 跟拍 | **首尾帧 + 视频参考（Blender 轨迹）** | 双轴耦合，文字必崩，非图控不可 |
| dolly zoom / 多轴复合 | 视频参考为主，甚至拆成多段 | 模型几乎无法一次性正确采样 |

**④ 运动幅度做减法。**
生成式里**一个镜头只承载一个主运动**最稳。想要「推进 + 环绕 + 上升」，拆成三个镜头分别生成再剪，远比逼模型一镜完成可靠。
> 符合「不给单元加不承载的重量」——把复合运动的重量拆到多个可控单元里。

## 九、落地：运动进 spec 的字段结构

```yaml
camera_motion (相机运动):
  geometry:                          # 几何：哪条轴在动
    type: 固定/推/拉/横移/升/降/pan/tilt/环绕/crane/跟拍/dolly_zoom
    axes: [ΔZ, ΔPan, ...]            # 底层轴，消歧用
    amount: 幅度（起点姿态→终点姿态）
    speed_curve: 匀速/缓入缓出/加速   # 运动曲线
  texture:                           # 质感：怎么动（正交）
    rig: 固定/轨道/斯坦尼康/手持/稳定器/航拍
  motivation: 主体驱动/揭示驱动/情绪驱动   # 为什么动（语义锚）

  # —— 生成式执行层 ——
  control_tier: 纯文字/首帧/首尾帧/视频参考
  previs_ref: <Blender 轨迹 playblast 路径>   # 复杂运动必填
  start_frame: <首帧构图>
  end_frame: <尾帧构图>
```

> `motivation` 是唯一不能穷举、必须人写的一维——几何和质感是物理，可枚举；动机回答「这个运动为什么存在」，是防止运镜沦为炫技的 load-bearing 字段。
> **一个没有动机的华丽运镜，就是最该砍掉的那种「增重不承载」。**

## 附：关联维度

- **机位**：运动 = 机位静态姿态值随时间变化（运动是机位的「导数」）
- **焦段 / 焦距**：zoom 是焦距随时间变；dolly zoom 是运动与焦段的深度耦合
- **景别**：dolly 改摄距 → 改景别；zoom 改焦距 → 也改景别（但透视不同）
- **轴线 / 越轴**：运动轴线的越轴靠骑轴运镜解决；跟拍建立在运动轴线上
- **视点归属**：跟拍相位（前/后/侧）关联主观/客观倾向
