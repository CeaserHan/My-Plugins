# 构图规则

## 适用条件

详细设计中组织视觉焦点、视线进入顺序、主体位置、留白、遮挡、画框与层次；按镜头功能决定描述密度。

## 决策步骤

1. 明确观众第一眼、第二眼和最后应看到什么。
2. 依据主体朝向和运动方向留出视线空间或运动空间；需要压迫时再有意减少。
3. 用三分、中心、对称、对角线、负空间、前景遮挡或框中框组织关系，但每种形式都要服务信息。
4. 只有当空间层次影响焦点、遮挡或关系时才写前景/中景/后景；特写、干净近景、俯视大全景等不机械补齐三层。
5. 检查相邻镜头的视觉重心与视线路径，避免无意跳动。

## 例外

故意失衡、截断、极端留白或遮挡可用于主观压力和延迟揭示；必须确保关键动作仍可读。

## 失败代价

构图若只堆术语，会遮蔽主要动作；机械三层描述会制造不存在的空间，视觉焦点不清则削弱信息揭示。
