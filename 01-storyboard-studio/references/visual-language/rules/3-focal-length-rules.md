# 焦段规则

## 适用条件

详细设计内部始终判断透视、空间压缩、人物脸部比例、背景关系和运动速度感；默认不把焦段写进成品。

## 决策步骤

1. 先确定需要保留的空间深度、人物距离和背景信息。
2. 判断摄像机能否移动到满足构图的位置，再选择与该距离匹配的视角范围；不要用裁切概念代替透视判断。
3. 需要强调纵深、靠近感或运动速度时考虑较广视角；需要压缩距离、隔离主体或安静背景时考虑较窄视角。
4. 检查面部变形、背景尺度、运动视差和相邻镜头透视是否连续。
5. 只有用户明确要求焦段时，才输出焦段或毫米数；否则只让判断体现在画面关系里。

## 例外

刻意畸变、窥视、压缩或主观不适可以突破自然透视，但需与叙事节拍绑定。空间狭窄不自动等于必须使用广角。

## 失败代价

忽略焦段会让人物比例、空间大小和运动感在镜间跳变；默认输出毫米数又会给用户造成无必要负担或虚假精确。
