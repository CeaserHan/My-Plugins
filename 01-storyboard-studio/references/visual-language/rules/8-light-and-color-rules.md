# 影调与色彩规则

## 适用条件

草稿阶段建立场景视觉基调；详细设计阶段锁定光源、方向、软硬、明暗层级、色彩关系与镜间连续性。

## 决策步骤

1. 从时段、地点和可见光源确定主光依据，不凭空添加无法解释的方向。
2. 决定主体与背景的亮度关系、阴影信息量和对比强度，让它们服务叙事可见性。
3. 选择主色、辅色和必要的色彩对比；把色彩变化绑定到空间、时间或人物状态变化。
4. 把主光方向和人物受光面写入连续性账本，复核反打、走位和长镜头路径。
5. 描述最终可见效果，不堆砌灯具清单；不得用“电影感”代替具体明暗关系。

## 例外

超现实、记忆、梦境或有意不连续可以改变光色逻辑，但必须由文本或用户方向支持，并明确变化边界。

## 失败代价

光源方向跳变会破坏空间连续性；人物融入背景会丢失动作；无动机色彩变化会制造错误的时间或情绪信息。
