# 机位规则

## 适用条件

详细设计中为每镜确定摄像机高度、垂直角度与纵轴向方位角。它们共同决定信息可见性、人物关系和主观距离。

## 决策步骤

1. 先从场面调度确定拍摄侧与主体朝向。
2. 选高度：只使用 `眼高、腰高、膝高、贴地、高位`。眼高保持同等观察；腰高、膝高或贴地改变身体与环境比例；高位交代平面关系或压低主体。
3. 选垂直角度：平视、俯视、仰视必须服务空间信息或关系变化，不把俯仰机械等同于强弱。
4. 选纵轴向方位角：正视、侧视、左/右四分之三侧、背面、左/右后四分之三侧，根据表演可见度、视线方向和遮挡决定。成品写成 `纵轴向正视`、`纵轴向左四分之三侧` 等独立槽位。
5. 与前后镜的视线、轴线和光源方向复核。

## 例外

主观镜头、极端空间信息或有意制造失衡时可以在内部判断非常规物理位置，但成品高度字段仍映射到五档：肩高/胸高归入眼高，航拍/顶置归入高位，地面/地穴归入贴地；极端程度写进画面关系，不新增高度词。必须说明本镜获得了什么信息，不能只为视觉新奇。

## 失败代价

机位若与调度脱节，会造成视线错误、人物方向混乱、表演不可见或无动机的权力暗示。
