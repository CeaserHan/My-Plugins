# 轴线规则

## 适用条件

多人关系、对话、人物运动或视线匹配出现时，建立关系轴、运动轴与视线轴，并在连续性账本中记录拍摄侧。

## 决策步骤

1. 判断本镜主导轴线是哪一种，避免同时把所有几何线都当成同等约束。
2. 标记人物朝向、看向对象、运动方向与摄影机所在侧。
3. 相邻镜头检查左右方向、视线角度和背景关系是否可读。
4. 需要越轴时，使用轴上镜头、可见的摄像机移动、主体重新调度或明确建立新空间关系，让观众看到轴线如何改变。
5. 多轴线场景按叙事焦点切换主导轴，并在切换点重建关系。

## 例外

迷失、失控或主观断裂可以故意越轴，但要确认混乱是目标而非疏忽；后续若要恢复清晰，必须重新建立空间。

## 失败代价

无意越轴会让人物互看方向、进出方向和追逐路径翻转，直接损害动作因果与情绪接力。
