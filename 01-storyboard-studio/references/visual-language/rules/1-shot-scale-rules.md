# 景别规则

## 适用条件

草稿拆镜时决定每镜景别并建立全场景别曲线；详细设计阶段只读取并冻结锁定景别，确认构图、机位、运镜和调度没有改变它。景别首先决定观众获得多少空间、关系、动作或表演信息。

## 决策步骤

1. 草稿阶段先写本镜唯一主要信息：空间、关系、动作、表演或细节。
2. 草稿阶段按信息选择景别：空间和群体关系优先远景/全景；完整身体动作优先全景/中景；交流和表演优先中景/中近景/近景；不可替代的细节才用特写。
3. 草稿阶段把单镜选择放进整场曲线，检查靠近或拉远是否对应分镜节奏，并检查相邻景别是否造成无意跳切。
4. 详细设计阶段逐镜复制锁定景别；推拉、跟拍、调度和重新构图都必须在该景别允许的画面范围内完成。

## 例外

草稿阶段为了压缩空间、延迟揭示或制造疏离，可以不用常规建立镜头，但必须在导演讲戏稿中说明目的。详细设计若需要改变锁定景别，必须停止并回到草稿阶段重新批准；特写不要求填写前中后景。

## 失败代价

景别过宽会丢失关键反应，过近会丢失空间因果；草稿阶段机械轮换会让剪辑节奏与叙事脱节，详细阶段静默改景别则会破坏已批准契约。
