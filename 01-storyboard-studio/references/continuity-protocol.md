# 连续性协议

详细镜头设计前建立隐藏连续性账本，逐镜更新但默认不展示。用户要求时才输出相关条目。

## 账本字段

| 维度 | 必须记录的状态 |
|---|---|
| 人物 | 外观、服装、手持物、身体状态、入画与出画方向 |
| 位置 | 场景锚点、相对站位、人物距离、朝向和视线目标 |
| 动作 | 已完成、进行中、待发生的动作；动作手与动作顺序 |
| 道具 | 所属者、位置、朝向、开合/完整/消耗状态、最后一次变化 |
| 空间 | 出入口、窗、家具、前景遮挡、可通行路径和不可跨越边界 |
| 轴线 | 关系轴、视线轴、运动轴、当前摄影侧和允许的越轴方法 |
| 光线 | 主光来源、方向、硬软、色温、时段与人物受光面 |

## 更新流程

1. 从原始文本与锁定草稿建立场首状态。
2. 每设计一镜，先读取上一镜结束状态，再写本镜开始状态。
3. 本镜动作结束后更新人物、道具、轴线和光线状态。
4. 若设计要求与账本冲突，优先调整设计；不得改锁定事实来迁就构图。
5. 场景切换或明确跳时后建立新分区，同时保留需要跨场延续的服装、道具和人物状态。

## 冲突处理

无法同时满足锁定草稿和连续性时，停止并报告：冲突镜头 ID、前一有效状态、当前要求、两者为何不能同时成立、需要用户决定的问题。不要静默补人物、复制角色、移动门窗或改变光源方向。

## 最终审查

逐镜检查主体唯一性、左右方向、视线匹配、动作衔接、道具去向、轴线侧、光源方向与信息揭示顺序。连续性账本是内部约束，不增加最终每镜两行格式的字段。
