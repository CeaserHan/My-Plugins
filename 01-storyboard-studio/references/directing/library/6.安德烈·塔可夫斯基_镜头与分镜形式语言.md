# 安德烈·塔可夫斯基：镜头与分镜形式语言

## 导言

安德烈·塔可夫斯基常被概括为“诗电影”“宗教电影”或“慢电影”导演，但这些标签很容易让分镜学习停留在表面：长镜头、积水、雾气、废墟、梦境和缓慢行走。真正值得研究的，是他怎样让时间本身成为画面材料，怎样让摄影机不急于解释，而是在空间中持续观察；怎样通过极慢的构图变化、人物位移、声音、反射和环境运动，使一个镜头在内部逐渐发生意义变化。

塔可夫斯基把电影创作形容为“雕刻时光”。这并不等于镜头越长越好，而是认为每个镜头内部都具有独特的时间压力和节奏，剪辑应连接这些已经存在于镜头内部的时间，而不是依靠外部节拍强行制造速度。[1][2]

他的形式方法可以用于任何题材。家庭、校园、都市、爱情、科幻、悬疑或日常生活，都可以借鉴他对持续时间、空间层次、人物与环境关系以及声画节奏的处理，而不必复制其宗教主题、末日意象或自然符号。

## 一、时间与镜头持续

### 1. 长镜头的核心是“让变化真正发生”

塔可夫斯基的长镜头并不是简单延长一个稳定构图。镜头持续期间，画面通常会发生细微但持续的变化：

- 人物在空间中缓慢移动；
- 摄影机改变观看位置；
- 光线、烟雾、水面或风发生变化；
- 前景遮挡逐渐解除；
- 画外声音改变观众对画面的理解；
- 原本处于背景的区域逐渐成为重点；
- 人物停顿后，空间本身开始被观众注意。

镜头之所以需要持续，是因为这些变化必须经历真实时间。若过早切走，观众只能知道“发生了什么”，却无法感受变化怎样形成。

### 2. 镜头长度来自内部事件，而非固定风格

塔可夫斯基式长镜头没有统一时长。一个镜头应该持续多久，取决于画面内部需要多少时间才能完成感知。

例如：

- 人物从房间深处走到前景；
- 摄影机沿墙面、物体和人物逐步移动；
- 一段环境声使普通空间逐渐产生新的含义；
- 观众需要时间辨认镜面、门口和真实空间之间的关系；
- 一次停顿需要持续到人物动作的惯性完全消失。

因此，长镜头的长度不是审美姿态，而是镜头内部变化完成所需要的时间。

### 3. “等待”是一种画面内容

普通分镜经常把停顿视为没有信息的部分，而塔可夫斯基会让等待本身成为可感知的事件。

当人物不说话、不移动时，观众开始注意：

- 人物的呼吸与重心；
- 空间的深度；
- 画外声音；
- 微弱的光影变化；
- 环境中缓慢移动的物体；
- 人物与环境之间的距离。

这种停顿会把观看从“追踪剧情”转为“观察存在状态”。

### 4. 镜头内部的时间压力

塔可夫斯基认为电影节奏不只是由剪辑速度决定，而来自每个镜头内部所携带的时间压力。[2]

所谓时间压力，可以理解为：

- 画面中的变化正在积累，但尚未完成；
- 人物似乎要行动，却迟迟没有行动；
- 摄影机缓慢接近一个区域；
- 声音预示画外事件，但画面仍然保持不动；
- 某种环境变化不断增强；
- 镜头持续到观众不再期待传统切镜。

镜头内部的压力达到某个程度后，切镜才显得自然。

## 二、视觉构图

### 1. 构图具有缓慢变化的能力

塔可夫斯基的构图常在镜头开始时显得稳定，但随着人物和摄影机移动，画面会逐渐重组。

例如：

- 开始时人物在画面边缘，随后走入中心；
- 前景物体遮挡主体，人物移动后空间被打开；
- 镜头起初强调环境，最终落在人物身上；
- 人物离开后，原本作为背景的空间成为新的主体；
- 摄影机缓慢转动，使画面中的真实空间和反射空间交换位置。

这种变化不是突然的构图替换，而是一个构图逐渐演化为另一个构图。

### 2. 人物不必始终是视觉中心

人物可能位于画面边缘、后景、门口或阴影中。摄影机有时会暂时离开人物，观察墙面、桌面、水面、空房间或自然环境。

这并不意味着人物被忽略，而是让观众通过环境重新理解人物。空间可以保留人物刚刚留下的痕迹，也可以在人物尚未进入时先建立等待。

### 3. 画面中的水平、垂直与纵深

塔可夫斯基的画面经常由清楚的建筑线条、地平线、墙面、门框和道路组织。

- 水平结构使画面获得稳定和延展感；
- 垂直线条形成空间边界；
- 纵深通道使人物能够缓慢接近或离开；
- 门窗和开口把多个空间层连接起来；
- 镜面与水面复制或扰乱这些几何关系。

构图看似自然，但空间线条往往经过高度控制。

### 4. 画面密度偏低，但信息并不少

塔可夫斯基的画面常比高密度商业影像更空，但空并不等于缺少信息。

少量人物、家具、门窗、自然物和声音之间的关系会被放大。因为画面没有被大量动作填满，观众更容易注意到：

- 一个物体的位置；
- 人物与物体的距离；
- 空间中的湿度和质感；
- 细小的环境变化；
- 人物停留与离开的痕迹。

## 三、景别与镜头尺度

### 1. 中远景保留人物与环境的完整关系

塔可夫斯基常使用中远景或全景，让人物身体、行动路径和环境同时存在。

人物的情绪不完全依赖面部近景，而可以通过：

- 走路速度；
- 身体停顿；
- 转身；
- 与门窗、墙面和物体的距离；
- 在空旷空间中的比例；
- 进入或离开画面的方式

被观众感知。

### 2. 近景不是单纯的情绪放大

近景经常在人物已经与空间建立关系后出现。它可以让观众突然注意：

- 面部的细微停顿；
- 手接触某个物体；
- 皮肤、衣物和水的质感；
- 一个视线并未明确指向的心理状态；
- 人物与背景之间的模糊边界。

这种近景通常不会通过快速切换获得冲击，而是持续到人物的微小变化被看见。

### 3. 景别变化经常由摄影机完成

与依靠剪辑直接切近不同，塔可夫斯基常让摄影机缓慢靠近、离开或横向移动，使景别变化成为连续时间的一部分。

缓慢接近不会像快速推进那样明确宣布“这里重要”，而是让观众逐渐意识到视觉重点正在变化。摄影机离开人物时，也可能让环境重新获得重量。

### 4. 人物大小可以在同一镜头中发生多次变化

人物从后景进入中景，再经过摄影机走出画面，一个镜头可以完成多个景别阶段。

这种处理保留了人物动作的完整路径，也使人物与空间的关系不断变化：

```text
环境中的小人物
→ 可辨认的身体
→ 接近观众的具体人物
→ 离开后重新留下环境
```

## 四、摄影机运动

### 1. 摄影机运动缓慢但并非被动

塔可夫斯基的摄影机经常以很慢的速度移动，但运动具有明确选择。

它可能：

- 沿着人物行进；
- 在人物停止后继续前进；
- 从人物转向物体或环境；
- 穿过门口进入另一个空间层；
- 沿墙面、桌面、水面或地面移动；
- 从真实人物移动到镜中影像；
- 在人物离开后停留于空空间。

缓慢运动让观众能够感知观看位置的变化，而不是只注意运动效果。

### 2. 摄影机与人物不总是同步

常规跟拍会让摄影机与人物保持稳定关系，而塔可夫斯基经常让两者发生偏离。

- 人物移动，摄影机暂时不跟；
- 摄影机移动，人物保持静止；
- 人物离开画面，摄影机继续观察空间；
- 摄影机先进入新区域，人物随后出现；
- 人物和摄影机以不同速度移动。

这种不同步使摄影机具有独立意识，也让环境不只是人物行动的背景。

### 3. 横移和缓慢转向重新连接空间

缓慢横移可以把不同人物、物体和空间区域连接为一个连续整体。

摄影机可能先观察人物，再经过前景物体，最后落到另一个空间。移动过程中，观众必须不断重新判断：

- 哪一层是现实空间；
- 哪一层是反射；
- 谁仍在画外存在；
- 画面的主次关系怎样改变。

### 4. 摄影机有时故意拒绝追随动作

当人物突然离开时，摄影机未必马上跟随。它可以停留在人物离开后的空间，让动作的结果通过空画面和声音继续存在。

这种选择会让“缺席”成为画面内容。观众不仅看到人物去了哪里，也感受到人物离开后留下了什么。

## 五、前景、中景与后景

### 1. 三层空间具有持续时间

塔可夫斯基的前中后景并非只为了制造漂亮景深，而是让不同时间同时存在。

- 前景可能保留过去动作留下的物体；
- 中景是当前人物所在位置；
- 后景可能等待下一次进入；
- 镜面或窗外空间可能显示另一个同时发生的层次；
- 画外声音让不可见空间继续存在。

因此，多层空间也是多层时间。

### 2. 前景形成观看阻力

门框、家具、墙面、植物、布料和人物身体可以部分遮挡画面。

这种遮挡不会立即被消除，而是迫使观众从有限角度观察。随着摄影机或人物移动，空间逐渐显露。

前景阻力使观看不再完全透明。观众需要主动辨认画面，而不是被立即交代全部信息。

### 3. 中景承载人物存在状态

人物通常在中景中完成缓慢行走、停顿、转身和接触物体。

中景既足以看见身体，也保留周围空间，因此适合表现人物不是“做一个动作”，而是“在某个空间中停留”。

### 4. 后景可以长期保持潜在状态

后景中的门口、走廊、树木、窗户或人物，可能长时间不成为主信息，但持续影响画面。

当后景突然发生变化时，观众已经熟悉它的位置，因此变化不需要快速剪辑也能被察觉。

### 5. 反射增加空间歧义

镜子、玻璃、水面和金属反光，会把不同空间叠加在同一画面中。

反射可以：

- 让人物同时存在于真实空间和影像空间；
- 延伸画面纵深；
- 让观众暂时无法确定人物朝向；
- 将画外区域带入画面；
- 使一个空间看起来包含另一个空间；
- 让人物和环境的边界变得不稳定。

反射不一定意味着象征或梦境，它首先是一种复杂空间构图方法。

## 六、环境运动与物质质感

### 1. 水具有多重形式功能

塔可夫斯基画面中的水常以积水、雨、滴落、河流、水汽和潮湿表面出现。

从纯形式角度看，水可以：

- 产生反射；
- 让静止画面出现微小运动；
- 改变光线；
- 连接前景与后景；
- 放大声音细节；
- 让物体和空间具有时间侵蚀感；
- 使人物行动速度发生变化。

水不是必须复制的导演标志，重要的是理解可运动材质怎样参与构图。

### 2. 风、烟、火和布料让空间呼吸

当人物保持静止时，树叶、窗帘、烟雾、火焰和衣物仍然能够运动。

这些环境运动可以：

- 维持画面活性；
- 指示空间方向；
- 连接看不见的画外区域；
- 与人物的静止形成对比；
- 让空间显得拥有独立生命；
- 提醒观众时间仍在流动。

### 3. 质感通过持续观察被放大

墙面剥落、木材、泥土、金属、玻璃和织物，在较长镜头和近距离观察中会获得强烈存在感。

质感不是美术细节的堆积，而来自光线、声音、湿度和人物接触方式的共同作用。

### 4. 环境不是插入空镜，而是持续参与

塔可夫斯基并非简单在人物场景之间加入自然空镜。环境常与人物处于同一个镜头，或者在人物离开后继续存在。

环境因此不只是转场素材，而是人物调度和镜头时间的一部分。

## 七、人物调度

### 1. 人物移动缓慢且路径清楚

塔可夫斯基的人物经常以较慢速度穿过房间、走廊、田野和门口。

缓慢移动使观众能够注意：

- 人物的完整路线；
- 每次停顿发生在哪里；
- 人物与物体怎样接触；
- 人物进入不同空间层后的大小变化；
- 环境如何影响行走。

走路不是连接两个剧情点，而是建立人物与空间的关系。

### 2. 停顿比动作结果更重要

人物到达某处后，常不会立即开始下一动作，而会停留、观察、转身或沉默。

停顿让前一个动作的影响保留下来，也使后续动作不显得只是功能性推进。

### 3. 人物可能背对摄影机

背面、侧面和被遮挡的身体经常出现。摄影机不要求人物始终面向观众，也不会为了看清表情而频繁换位。

人物背对镜头时，观众会更多依赖：

- 姿态；
- 头部轻微转动；
- 手部动作；
- 身体与环境的距离；
- 声音和停顿。

### 4. 人物与物体的接触具有重量

拿起、放下、抚摸、擦拭、跨过和注视物体等动作，经常被完整保留。

物体不是推动剧情的快捷道具，而是人物与空间建立物理联系的媒介。

### 5. 多人物调度保持距离感

多人场景中，人物不一定聚集在同一平面。他们可能分别处于前景、门口、房间深处或画外。

这种分散调度使对话不只发生在脸与脸之间，而发生在完整空间中。人物之间的距离、朝向和沉默与语言同样重要。

## 八、分镜组织

### 1. 分镜按“时间段落”而非动作碎片组织

塔可夫斯基式分镜不会把每个小动作都拆成独立镜头。一个镜头往往包含完整的时间段落：

- 人物进入；
- 经过空间；
- 停留；
- 与物体接触；
- 摄影机改变位置；
- 人物离开；
- 空间继续存在。

这个段落内部可以有多个视觉重点，但它们共享同一段连续时间。

### 2. 一个镜头内部可以包含多个构图

长镜头并不意味着只画一张分镜。为了准确设计，仍然需要标出镜头内部的关键构图节点：

1. 起始构图；
2. 人物第一次改变位置；
3. 摄影机运动后的中间构图；
4. 视觉重点转移；
5. 最终落点；
6. 人物离开后的残留构图。

这样既保留长镜头，又能清楚规划内部调度。

### 3. 转场可以依靠声音、形状和运动

场景之间不一定通过传统建立镜头连接。塔可夫斯基常利用：

- 相似运动；
- 相似形状；
- 水、风、火等材质；
- 画外声音提前出现；
- 人物动作在下一空间获得回应；
- 明暗或色彩变化；
- 反射和真实空间之间的转换。

这种连接更接近感知关联，而不是纯粹地理连续。

### 4. 梦、记忆与现实可共享同一种镜头语法

塔可夫斯基不会总用模糊滤镜或特殊效果明确标记梦境。现实、记忆和梦可以采用相近的镜头速度、构图和物质质感。

区分可能来自：

- 空间关系无法完全解释；
- 人物年龄或位置变化；
- 色彩和黑白变化；
- 声音不符合画面来源；
- 某个动作或形状在不同时空重复。

《镜子》将多个时代、记忆和影像材料并置，形成非线性但具有感知连续性的结构。[3]

## 九、剪辑与节奏

### 1. 剪辑连接不同的“时间压力”

塔可夫斯基并不追求通过快速剪辑制造节奏。他认为节奏已经存在于镜头内部，剪辑需要判断两个镜头的时间强度是否能够连接。[2]

一个镜头可能平静但具有持续压力，另一个镜头可能运动更明显却时间较松。剪辑需要处理两者之间的呼吸，而不是只比较镜头秒数。

### 2. 切镜通常发生在内部时间完成后

镜头不会因为动作刚完成就立即切走。它可能继续停留，让动作余波被感知。

相反，有时镜头也会在传统动作尚未完全完成时切换，把动作结果交给声音或下一镜头。这取决于当前时间段落是否已经完整，而不是动作是否被机械交代完毕。

### 3. 节奏来自持续与断裂的对比

塔可夫斯基虽然以长镜头著称，但影片并非没有强烈断裂。

节奏可以来自：

- 长时间观察后突然切换；
- 安静环境后出现强烈声音；
- 连续现实后进入记忆影像；
- 稳定画面后出现快速运动；
- 彩色、黑白或不同影像质感之间的变化；
- 人物场景与空空间之间的切换。

长镜头只有与这些变化形成关系，才真正具有节奏。

### 4. 重复建立内部韵律

某些动作、物体、空间和声音会在不同段落中重复出现。

重复不是简单提示象征，而会使观众在观看后续画面时记起前面的时间。一个普通物体再次出现时，已经携带此前镜头的持续感。

---

## 十、声音与画面的关系

### 1. 声音扩展不可见空间

画外脚步、风声、滴水、车辆、机械、动物和远处人声，会让画面之外的空间持续存在。

声音不一定被画面立即解释。观众可能先听见某种声音，过一段时间才知道来源，或者始终无法确认来源。

### 2. 环境声不是背景填充

环境声具有层次、距离和方向。近处滴水、远处轰鸣、室内回声和风穿过建筑的声音，会共同建立空间体积。

即使画面静止，声音仍然能使观众感到空间正在变化。

### 3. 声画可以保持距离

画面中的动作不一定配以最直接的同步声。某些声音可能被压低、延迟、放大或由其他空间的声音覆盖。

这种距离使观众不只关注动作本身，也关注人物怎样感知动作。

### 4. 音乐使用克制

音乐并不持续解释情绪，而经常与环境声、沉默和现实声音形成间隔。

音乐出现时，往往会改变整段画面的时间质感，而不是只为某个表情提供情绪提示。

---

## 十一、可迁移的形式要点

- 镜头时长应由内部变化完成所需要的时间决定。
- 长镜头内部仍需要多个清楚的构图节点。
- 人物不必始终占据中心，环境可以暂时成为主体。
- 摄影机可以与人物不同步，使空间获得独立存在。
- 前景遮挡、中景人物与后景入口可以共同形成缓慢展开的空间。
- 环境运动能够让静止画面保持时间感。
- 人物走路、停顿和接触物体都可以成为完整的画面事件。
- 剪辑应连接镜头内部的时间强度，而不只是追求快慢变化。
- 声音可以扩展画外空间，也可以改变观众对静止画面的理解。
- 塔可夫斯基式形式不等于长、慢和自然意象的机械叠加。

---

## 十二、容易产生的误读

塔可夫斯基的形式语言不等于：

- 所有镜头都必须很长；
- 人物必须缓慢行走；
- 画面必须出现雨、水、火、雾和废墟；
- 所有对白都要停顿；
- 镜头越少越高级；
- 情节越难理解越接近诗意；
- 摄影机只能缓慢移动；
- 任何空镜都具有深刻意义。

真正值得借鉴的是他对镜头内部时间的控制。一个镜头为什么必须持续，空间在持续过程中怎样变化，人物和摄影机为什么不同步，环境与声音怎样参与调度，才是其形式语言的核心。

若镜头内部没有新的感知变化，单纯延长时长只会造成空洞；若水、火、雾和反射与当前空间没有关系，它们也只会成为表面模仿。

---

## 延伸观看

可重点观察以下作品的形式处理：

- 《伊万的童年》：主客观空间、纵深运动和现实与记忆的转换；
- 《安德烈·卢布廖夫》：大空间中的人物比例、环境运动与持续时间；
- 《飞向太空》：走廊、反射、缓慢摄影机运动与空间连续；
- 《镜子》：记忆结构、色彩变化、室内外空间和声音连接；
- 《潜行者》：人物行进、前中后景、材质和空间等待；
- 《乡愁》：长镜头内部的路径、停顿和人物与建筑关系；
- 《牺牲》：复杂长镜头、人物调度、景观与环境运动。
